# 사전등록 — P2 위치 변경 보정 (원단위 R² 고도화 2차)

등록 2026-10-22. P0 진단을 실행하기 전에 커밋한다. 커밋 이후 아래 조건·방식·정의를 바꾸지 않는다.
폴더 메모: `reports/experiments/EXP-005/` 의 기존 파일(README.md·metrics.json·VERIFY.md 등)은 1차 실험 R2(상류 피처)의 것이다. 2차 실험 산출물은 이 폴더의 `PREREG_*.md`·`EXP-summary2.md` 와 하위 폴더(`P0/`~`P6/`, `COMBO/`)에 둔다.

## 1. 사용자 지시 원문(그대로)

- 적용 조건: P0 b)에서 낙동강 4지점의 효과 방향이 같고 DiD 95% CI가 0을 포함하지 않을 때만 적용. 조건을 못 채우면 적용하지 않는다.
- 적용 방식: near_intake 지표 피처 + 지점별 log 오프셋(2025-09~10 잔차의 경험적 베이즈 수축 추정치). 추가 튜닝 금지.

## 2. 운영 정의(실행 전 확정)

**잔차(P0 b).** v1 CV 모델(학습 ≤2024, `data/processed/exp/baseline/oof.parquet` 의 `ens`)의 2025 행 log 잔차 e = log10(관측+1) − log10(예측+1).

**기간(목표일 기준).** 변경 전 = target_date 2025-01-01~2025-08-31, 변경 후 = target_date 2025-09-01~2025-10-31.

**집단.** 낙동강 N = {해평 HP, 강정·고령 GJGR, 칠서 CS, 물금·매리 MGMR}, 대조군 D = {회남 DCHN}.

**DiD.**
- 통합 평균 DiD Δ = (ē_N,후 − ē_N,전) − (ē_D,후 − ē_D,전). ē_N 은 4지점 행을 합친 평균이다.
- 지점별 Δ_s = (ē_s,후 − ē_s,전) − (ē_D,후 − ē_D,전).
- 분산 DiD = ln(var_N,후 / var_N,전) − ln(var_D,후 / var_D,전), 지점별도 같은 식이다.

**부트스트랩.** 지점×기간 층별로 행을 복원추출 5,000회 한다(생성기 시드 20261022). 95% 구간은 백분위수 방식이다.

**적용 조건 판정.** 지점별 평균 DiD Δ_s 의 부호가 4지점 모두 같고, 통합 평균 DiD Δ 의 95% CI 가 0 을 포함하지 않을 때 '적용'이다. 분산 DiD 와 P0 c) 추가 대조군은 판정에 쓰지 않는다(보고만).

**적용 방식(조건 충족 시에만, 추가 튜닝 없음).**
- `near_intake` = 1: 낙동강 4지점에서 base_date ≥ 지점별 채수 위치 변경일(P0 a 확정값)인 행이다. 그 밖은 0 이고, 회남은 항상 0 이다. 2020~2024 CV 와 2025 Final 폴드의 학습 구간(≤2024)에서는 상수 0 이라 효과가 없고, 최종 학습(2025 포함)에서만 의미가 있다.
- 지점별 log10 오프셋 o_s: 보정 대상 모델의 2025 잔차로 위 Δ_s 를 계산하고, 그 표본분산 v_s(부트스트랩 분산)를 구한다. τ² = max(0, DerSimonian–Laird 추정치), 가중평균 μ̂ = Σ w_s Δ_s / Σ w_s(w_s = 1/(v_s + τ²)), 수축계수 B_s = τ² / (τ² + v_s), o_s = μ̂ + B_s (Δ_s − μ̂) 다.
- 적용: near_intake = 1 인 행의 log10 예측에 o_s 를 더한다(원단위 = 10^(log10(예측+1) + o_s) − 1).
- 보정 대상 모델: 그 단계의 모델(P2 표에서는 기준 모델 C, 종합에서는 최종 후보)이다. 적용 조건 판정은 P0 b)(v1 잔차)로 한 번만 한다.

**평가(제자리 평가 방지).** 오프셋을 2025-09~10 자료로 추정하므로, 2025-09~10 행의 평가값은 그 행을 뺀 나머지로 o_s 를 다시 추정해 적용한다(한 행 빼기 교차 적합). CV 2020~2024 와 2025-01~08 은 near_intake = 0 이라 보정 전과 같다.

**조건 미충족 시.** P2 는 적용하지 않고, P2 표에는 '미적용(조건 미충족)'과 판정 값만 적는다.

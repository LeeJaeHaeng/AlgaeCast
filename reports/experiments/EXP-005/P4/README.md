## 1. 목적·설정

**목적.** (1) 칼만 필터로 현재 상태를 추정한다. (2) 추정한 측정 잡음 분산으로 "완벽한 모델도 넘을 수 없는" log·원단위 R² 상한을 구한다. (3) 필터 상태를 피처로, 칼만 예측을 앙상블 구성원으로 시험한다.

**자료.** 조류경보 원자료는 `data/raw/nier_algae/nier_algae_2012_2026.parquet`의 5지점 측정(세포수·수온)이다. 읽은 즉시 2025-12-31 이후 측정을 버렸다. 수온이 −1~40℃ 밖이면 결측으로 처리했다. 표본은 `harness.load_base()`(2,566행, 기준일 ≤2025)다.

**모형**(지점별, 상태 x = log10(세포수 + 1), 일 단위 격자, 측정 없는 날은 결측):
- **본 모형 `lltemp`(지시 그대로).** x_{d+1} = x_d + b0 + b1·(T_d − 15) + η_d, η ~ N(0, q). 측정 y_d = x_d + ε_d, ε ~ N(0, σ_ε²).
- 확장·민감도 모형:
  - `ll`: 성장항 없음.
  - `lltemp_r2`: 잡음을 5~10월과 11~4월 둘로 나눔.
  - `lltemp_lv`: ln σ_ε² 가 수준에 선형.
  - **`damped`(Gompertz형 밀도 의존 성장).** x_{d+1} = x_d + (1−φ)·(a0 + a1·(T_d − 15) − x_d) + η_d. 수온이 정하는 평형으로 되돌아가는 AR(1)이다.
  - `damped_r2`, `damped_lv`: damped 에 위와 같은 잡음 변형을 더한 것.
- **T_d** 는 그날까지의 마지막 실측 수온(전진 채움)이다. 측정일 사이에는 T가 일정하므로 k일 전이를 닫힌 식으로 한 번에 계산한다. 하루씩 돌린 일 단위 격자 필터와 수치가 같다(테스트 `test_event_filter_equals_daily_grid`, 7개 모형 전부).
- **초기화.** 첫 관측에서 산만 시작한다(m = y, P = σ_ε²). 첫 관측은 우도에서 뺀다.
- **7일 앞 예측** = 상태 전이 7회이고, 수온은 as_of 값을 유지한다. 구성원은 목표일까지 h = horizon_days 회 전이한다(80%가 7회, 나머지 4~10회).

**매개변수 추정(as_of 규칙).**
- 기준일이 Y 년인 행의 매개변수는 obs_date ≤ (Y−1)-12-31 측정으로 최대우도 추정한다(L-BFGS-B, 시작점 3개). 결과적으로 CV 연도 Y 행은 ≤Y−1, 2025 행은 ≤2024로 추정한다. 즉 검증 폴드의 학습 구간과 같다.
- 학습 행도 같은 규칙을 따른다. 따라서 모든 피처는 (원자료, as_of, 지점)의 순수 함수다.
- 지점 측정이 80개 미만이면 같은 기간 전 지점의 공통 매개변수를 쓴다(물금·매리 2020~2021 행, 낙동강 3지점 2016~2017 행). 그것도 없으면(회남 2012~2013 행) 값은 NaN이다.
- 필터는 obs_date ≤ as_of 측정만으로 돈다. 평활화(smoothing)는 쓰지 않았다.

**변형**(모두 C 위, 분위는 v1 동결 q90, 하이퍼파라미터 v1):

| 축 | 변형 | 내용 |
|---|---|---|
| 피처 | `P4_kf3`·`P4_kf5`·`P4_kfd3`·`P4_kfd5` | lltemp(kf_)·damped(kfd_) 필터의 level·pred7·sd(3열), + innov·drift(5열) |
| 대조군 | `*_ctrl` | 같은 열 수·같은 결측 위치의 표준정규 난수(`harness2.noise_like`). kf3·kfd3 대조군은 모양·결측 위치가 같아 같은 난수다(kf5·kfd5 도 마찬가지) |
| 구성원 | `P4_kf_member`·`P4_kf_member_mean`·`P4_kfd_member`·`P4_kfd_member_mean`·`P4_kflv_member`·`P4_kfdlv_member` | 칼만 목표일 예측을 원단위로 바꿔 연도 확장 NNLS 5번째 구성원으로 넣음. 중앙값 = 10^m − 1, 평균 = 로그정규 평균 |
| 참고 | `P4_b0_member` | 지속성 구성원 10^cell_log_t0 − 1(선택 대상 아님. 칼만 고유 효과를 가르는 비교용) |

**선택 규칙(CV만, 탐색 시드 5개 평균, C 대비 시드 짝 차이).**
- 적격 조건: Δrmse_log ≤ +0.01, 리드타임 ≥ 18, 피처 변형은 고유 효과(Δ − Δ대조군) > 0.
- 피처와 구성원에서 각각 적격 최대 Δr2_raw 를 고르고, 둘 다 있으면 합친 변형(+ 대조군)을 더 돌린다.
- 최종 = 적격 변형 중 Δr2_raw 최대.
- 2025는 표에만 싣는다.
- 밝혀 둘 점: 수준 의존 잡음 구성원 2개(kflv·kfdlv)는 1차 표를 본 뒤 추가했다. 근거는 ≤2024 자료의 잡음 진단(아래 2.1)이다. 추가 후에도 선택은 바뀌지 않았다.

### 2.2 구간별 상한

정의와 가정:
- **log R² 상한** = 1 − Σσ_ε²(i) / Σ(ℓ_i − ℓ̄)², ℓ = log10(관측+1)이다. 진짜 상태를 정확히 아는 모형도 측정 잡음만큼은 틀린다.
- **원단위 상한(모의 A, 주 지표).** 단계는 다음과 같다.
  - 측정 잡음이 log 공간 정규, 즉 원단위 로그정규라고 가정한다.
  - 진짜 상태 x 의 사전분포를 지점·월별 N(μ, V − σ_ε²)(≤2024 측정)로 둔다.
  - 실제 관측 ℓ 이 주어졌을 때 x 를 사후분포 N(μ + k(ℓ − μ), kσ_ε²)(k = τ²/(τ² + σ_ε²))에서 뽑는다.
  - 같은 x 에서 새 측정 Y* = 10^(x+ε*) − 1 을 만든다.
  - 완벽한 예측 E[Y|x] = 10^x·exp(½(ln10·σ_ε)²) − 1 로 R² 를 계산한다.
  - 이 과정을 4,000회(민감도 출처는 1,000회) 반복해 평균·중앙값·5~95% 를 낸다. 구간 정의는 표준 표와 같다.
- 보조 지표 두 가지는 `ceiling.md` 에 있다.
  - B: 같은 x 로 실제 관측을 맞히는 경우. 최대 관측 행의 x 불확실성이 그대로 증폭돼 평균이 크게 음수다.
  - 관측=진짜(낙관): 관측값을 진짜 상태로 보고 잡음을 새로 더하는 경우.

값은 평균(중앙값) [5%, 95%]다. 고수준 γ 시나리오는 목표값 ≥ 10³ 행의 σ_ε² 를 min(lltemp σ_ε², 경보기 3~4일 짝 γ)로 바꾼 것이다. γ 가 σ_ε² 보다 크거나 같으므로 보수적이다.

읽는 법:
1. **log R²**
   - 잡음 상한이 0.91~0.95라 C(0.71~0.78)와 간격이 크다.
   - 칼만 모형이 스스로 기대하는 7일 예측 log R²(σ_ε² + 7일 상태 분산)는 lltemp 0.70, damped 0.74다. 실제 값은 0.65·0.70이다. C(0.713)는 이 수준이다.
   - 즉 남은 간격은 대부분 7일 동안의 상태 혁신(7q = 0.22~0.50 log10²)이다. 한 지점의 세포수 이력만으로는 알 수 없는 부분이라, 기상·수문·상류 같은 외부 정보로만 줄일 수 있다.
   - 2025 9~10월은 분산이 작아(0.36) 잡음 상한 자체가 0.46~0.75로 낮다.
2. **원단위 R²**
   - 상한이 잡음 모형에 따라 CV 0.41~0.82로 움직인다. 원단위 지표는 봉우리 몇 행이 좌우하고, 봉우리 수준의 잡음 크기가 상한을 결정하기 때문이다.
   - 증거(우도 비교와 경보기 짝 반변동)는 고농도에서 잡음이 작다는 쪽이라, 상한은 CV 약 0.6~0.8, 2025 약 0.5~0.65가 더 그럴듯하다.
   - 2025는 90% 범위가 [0.0~0.1, 0.85~0.91]로 넓다. 완벽한 모형이라도 한 해 단위 원단위 R² 는 운에 크게 좌우된다는 뜻이다.
   - 따라서 원단위 R² 0.6은 물리적으로 불가능한 목표는 아니지만, 측정 잡음만으로도 해마다 0.6 아래로 떨어질 수 있는 수준이다.
3. **잡음 비중.** C 의 CV log 오차 분산(0.796² = 0.634) 가운데 측정 잡음은 0.11~0.20(17~32%)이다.

- **피처.**
  - 필터 상태는 v1 피처(cell_log_t0·lag·max_4w·slope)가 이미 담은 정보를 매끈하게 다시 쓴 것에 가깝다. 4묶음 모두 대조군보다도 원단위 R² 를 낮췄다.

- **선택.** CV OOF(2020~2024)와 탐색 시드 평균만 썼다. 상한 분석의 매개변수와 사전분포는 ≤2024 측정으로 만들었다. 혁신 점검만 2025 측정까지 필터링했고, 이는 보고용이다.
- **보호 파일.** `python scripts/exp_check_protected.py` 결과 "보호 파일 38개 중 변경 0개"다. 기존 파일은 고치지 않았다. ruff·black(110) 통과다.

- 상한 표: 약 30초.

## 8. 한계

- **σ_ε² 식별은 동역학 가정에 달려 있다.**
  - 랜덤 워크(지시 모형)는 AIC 로 크게 기각된다(−321~−351). 그래서 지시 모형의 상한(원단위 CV 0.41)은 보수적인 하한 쪽 값으로 봐야 한다.
  - 강정·고령은 감쇠 모형에서 σ_ε² 가 식별되지 않았다(95% [0.000, 12.7]).
- **잡음의 정의.** "측정 잡음"은 다음 주로 이어지지 않는 모든 변동이다. 채수 지점의 국지적 패치, 표층 스컴, 계수 오차가 섞여 있다. 같은 날 측정 반복이 없어 계수 오차만 따로 분리할 수 없다.
- **원단위 상한의 가정.** 로그정규 잡음, 지점·월 정규 사전분포, 수준 의존 모형에서는 관측값을 수준의 대리로 썼다. 0 값과 검출 하한 근처(log 0~1)는 정규 가정과 맞지 않는다. 수준 의존 모형이 이를 일부 흡수한다.
- **수온.** 일 단위 수온 자료가 없어 주 1회 실측 수온을 전진 채움했다. 예측 7일 동안은 as_of 수온을 유지했다.
- **피처 대조군.** kf3·kfd3(및 kf5·kfd5) 대조군은 모양·결측 위치가 같아 같은 난수 열이다(`noise_like` 정의대로).
- **변형 추가.** 수준 의존 구성원 2개는 1차 결과를 본 뒤 추가했다(선택에는 영향 없음). 이 실험의 모든 수치는 탐색 시드 값이며 최종 판정이 아니다.

## 1. 2026 차단

- **코드 경로.**
  - 표본은 `H.load_base()`(학습·검증 분할만, `guard_no_2026`)로 읽는다.
  - `build_features`·`fs_frame`·`member_oof`·`members`·`main` 이 모두 `guard_no_2026` 을 부른다.
  - `load_daily` 는 읽은 직후 `obs_date ≤ 2025-12-31` 만 남긴다.
  - C 구성원의 속별 타깃(`R3.load_algae`)과 리드타임 사건(`official_events_until`)도 2025-12-31 이후 측정을 읽은 즉시 버린다.
  - P1 코드에 2026·posthoc·격리 타깃·판정 시드를 가리키는 참조는 없다. 문자열 "2026" 은 착수 시각 상수 하나뿐이다.
- **산출물 날짜.** 다음 산출물의 기준일 최대가 모두 2025-12-29 다: 표본 2,566행, `C_11`·`P1_add_gbm_base_none_11`·`P1_K5_11`·`P1_add_gbm_base_none_lvl_11`·`P1_m_gbm_base_11` 캐시, `mech_features.parquet`(2,566행).
- **2025 지표 범위.** `harness2.scope_masks` 를 다시 계산했다.
  - CV 1,278행이고 목표일 최대는 2025-01-06 이다.
  - 2025 전체는 252행이고 목표일 최대는 2025-12-29 다. 기준일 2025 인 256행 중 목표일이 2026 인 4행은 빠진다.

  - 연도별 표(`year_r2`)의 2025 도 목표일 ≤ 2025 행만 쓴다.

## 2. 선택 절차(CV·탐색 시드만)

- **코드.** `summarize` 와 `choose` 가 쓰는 값은 다음뿐이다.

- **시드.** 캐시 폴더에 판정 시드(1001~5005) 파일은 0개다. P1 캐시는 108개 이름 × 시드 5개(11·22·33·44·55)뿐이다.
- **후처리·매개변수.**
  - `linear_lambda` 는 `select_lin_lambda` 가 CV 마스크(기준일 2020~2024) 행의 rmse_log 로만 고른다(`lin_lambda.json`: 0.896, 0.8095, 0.8091, 0.8081 → 100).

  - linear_tree 표준화와 GAM 매듭·중앙값·표준화는 학습 행으로만 정한다. RidgeCV 의 α 도 학습 폴드 안에서 GCV 로 정한다.
  - 평년·kNN·칼만은 이 실험에 없다.
- **사전 확정 시점.** P1 코드가 미커밋(untracked)이라 "선택 규칙은 실행 전 확정"을 git 으로 확인할 수 없다. 실행 로그 3개를 비교했다.

  - run2 에서는 base 대조군이 없다.
  - run3 에서는 base 대조군이 K5 다.
  - 세 실행 모두 구성 89개, 구성별 CV 값, 선택이 같다. 바뀐 것은 보고용 대조군 연결뿐이고, base 후보의 적격 판단은 대조군을 쓰지 않는다(8절 m6).

## 8. 문제 목록(모두 minor, critical·major 없음)

- **m1 — README 6절 서술 오류.** "mech·weak 묶음은 고유 효과가 0 이하라 적격 조건 (ii)에서 빠졌다"는 사실과 다르다. mech·weak 후보 24개 중 5개는 고유 효과가 > 0 이라 적격이었다: add_gam_weak_none +0.0014, add_gbm_mech_smear +0.0010, add_lin_mech_smear +0.0007, add_gam_weak_smear +0.0003, rep_gam_weak_none +0.0003. 이들은 CV r2_raw 가 낮아 선택되지 않았을 뿐이다. 선택 결과는 같다.
- **m2 — "GAM 결합은 2025 r2_raw 0.189 로 가장 높다".** base 묶음 안에서만 맞다. 전체 후보 중 2025 r2_raw 최대는 rep_gam_weak_none 0.2006·add_gam_weak_none 0.2004 다. 실행자 요약의 `gam_best_2025` 와 요약 문장은 범위를 밝혀야 한다(선택에는 쓰이지 않음).
- **m3 — "이득이 특정 연도에 몰리지는 않는다"(README 5절)는 부정확하다.** CV 5개 연도 중 2개가 나빠졌다. 통합 CV 이득은 2022·2024 에서 오고, 폴드 평균 이득은 +0.0018 이다(7절).
- **m4 — "시드 잡음 폭(±0.02~0.04) 안"은 근거가 맞지 않는다.** 시드 짝 차이는 5개 모두 양수(+0.005~+0.015)라 시드 잡음으로 설명되지 않는다. 불확실성의 실제 원인은 (연도·지점) 블록 표본 변동(부트스트랩 [−0.004, +0.016])과 후보 36개 중 최대를 고른 승자 편향이다. 결론(미미)은 같다.
- **m5 — K5 대조군 해석.** PREREG 문구를 글자 그대로 따랐으므로 위반은 아니다. 그런데 K5 가 C 보다 −0.019 낮아서, "대조군 대비 +0.030" 이 C 대비 차이(+0.011)보다 크게 나온다. 선택 구성은 '피처가 아닌 구성원 d' 만 더한 후보다. PREREG 의 "피처가 아닌 구성원은 그대로 둔다"를 적용하면 K = C + d + 난수 5열로 읽을 여지도 있다. 최종 판정에서 이 후보를 쓴다면 어느 정의를 쓸지 사용자 확인이 필요하다. 이번 결론에는 영향이 없다((a) 첫 조건이 크게 미달).
- **m6 — 사전 확정을 검증할 수 없다.** P1 코드·README 가 미커밋이라 선택 규칙·후보 범위가 결과를 보기 전에 정해졌는지 git 으로 확인할 수 없다. 실행 로그 3개 사이에서 바뀐 것은 base 후보의 보고용 대조군 연결(없음 → K5)뿐이다. 구성 89개·CV 값·선택은 같다. 2절에서 확인했듯 후보 범위를 바꿔도 선택은 같다.
- **m7 — 목표일 2026 인 4행의 정답값이 파일에 저장된다.** 새 중간 산출물 `data/processed/exp/EXP-005b/P1/chosen_oof_seed11.parquet` 의 `target_cells` 열에 들어 있다. P1 캐시 전체와 기존 C 캐시도 마찬가지다. 하네스 `save_oof` 의 기존 동작이고 어떤 지표·적합에도 쓰이지 않았다(값은 열람하지 않고 개수만 셌다). P1 고유의 위반은 아니지만, '2026 열람 금지' 관점에서는 하네스 수준의 정리가 필요할 수 있다.
- **m8 — 적격 조건에 2025 사건을 포함한 리드타임(≥ 18)이 들어 있다.** 모든 구성의 분위가 v1 동결이라 상수(18/20)이므로 이번 선택에는 영향이 없다. 하지만 원칙상 'CV 만으로 선택' 규칙과 어긋나는 항목이다.

- **m10 — 연도를 넘는 표본(기존 규칙).** `year_folds` 는 기준일 연도로 나눈다. 그래서 Final 학습(기준일 ≤ 2024)에 목표일이 2025-01 인 5행이 들어가고, CV 각 폴드에도 2~5행씩 들어간다. v1·C 와 같은 기존 규칙이고 후보와 기준 모델에 똑같이 적용되므로 P1 비교에는 영향이 없다. 기록만 남긴다.

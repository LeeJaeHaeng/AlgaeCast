## 1. 목적·설정

**사용자 지시(원문 요지).** 타깃을 log10(target+1) − log10(t0+1)(변화량)로 바꾸고, 예측 후 t0 에 더해 복원한다. LightGBM linear_tree·일반 LightGBM·GAM 을 비교한다. 성장 기작 피처(속별 최적 수온 기반 성장률(Q10/Arrhenius 형태), 체류시간 역수(희석률), 일사·일조, 수온×체류시간 상호작용)를 넣는다. 지점의 절대 수준을 담는 피처(지점 임베딩, 장기 평균, 위치 변경 시점을 넘나드는 장기 창)를 약화한 버전도 비교한다.

**t0 정의(코드 확인).** `features.ar.make_ar_features` 의 `cell_log_t0` 는 base_date(포함) 이전 마지막 유효 측정의 log10(세포수+1)이다. v1 표본 2,566행은 모두 base_date 가 측정일이다(`days_since_obs` = 0). 따라서 t0 는 기준일 측정이고 결측이 없다. Δ 의 평균은 −0.011, 표준편차는 0.90 이다.

**기준 모델.** C = v1 로그 앙상블(c1·c3·c2) + R2 상류 피처 5열 + R3 속별 구성원 cg, 분위는 v1 동결본이다. `harness2.c_pred` 의 탐색 시드 캐시("C")를 그대로 썼다. 분위는 모든 구성에서 v1 동결(q90=None)이라 리드타임은 모두 18/20 이다.

**Δ 구성원(`member_oof`).** 폴드는 harness 와 같은 연도 확장(`models.cv.year_folds`, 2020~2024 + Final 2025)이다. 학습 타깃은 Δ = target_log − cell_log_t0, 가중은 v1 C1 과 같은 w = 1 + α·target_log 다. 예측 Δ̂ 은 그 폴드 학습 Δ 의 [최소, 최대]로 자르고 lp = t0 + Δ̂ 로 복원한 뒤 [0, 7] 로 자른다.
- 원단위 복원 none 은 10^lp − 1 이다.
- 원단위 복원 smear 는 연도 확장 Duan 계수를 곱한다(`harness.expanding_fit_apply`). 연도 Y 의 계수는 Y 이전 CV OOF 잔차로 적합하고, 2020 은 1, 2025 는 2020~2024 전체로 적합한다.

| 모델 | 설정 |
|---|---|
| gbm | LightGBM, v1 C1 하이퍼파라미터 그대로(n_jobs=4) |
| lin | 위와 같고 `linear_tree=True`. LightGBM 권고대로 수치 열을 학습 행 평균·표준편차로 표준화했다(분기는 그대로, 잎 선형식에만 영향). 잎 L2 `linear_lambda` 는 v1 에 없는 새 값이다. 그래서 {0, 1, 10, 100} 중 base 묶음 Δ 구성원의 CV rmse_log(시드 평균, 로그 적합도 기준)가 가장 낮은 **100** 을 한 번 고정했다. CV rmse_log 는 0 일 때 0.896, 1 일 때 0.810, 10 일 때 0.809, 100 일 때 0.808 이다. 100 은 후보 범위의 끝값이지만, 1 이상에서는 차이가 0.002 이내다. |
| gam | 가법 모형: 수치 열마다 3차 B-스플라인(분위 매듭 5개, 범위 밖은 상수) + 결측 지시 + 범주 원핫 → 표준화 → RidgeCV(α ∈ 10^[−1, 4] 11개, 학습 폴드 안 GCV). 값 종류가 적어 매듭이 4개 미만이면 선형 항으로 둔다. pygam 은 설치하지 않았고 sklearn 으로 구현했다. |

**결합.** 결합은 `harness.ensemble_expanding`(연도 확장 NNLS, log 공간) 하나로 한다. add 는 c1·c3·c2·cg 에 d 를 더한 5개 구성원이고, rep 는 c1 을 d 로 바꾼다. solo(d 단독 점예측)는 진단용으로만 계산했고 선택 후보에서 뺐다.

**피처 묶음.**
- base: v1 30열 + F2 5열(C 와 같다).
- mech: base + 성장 기작 9열.
- weak: 약화 기본 열 + F2(상류 절대 log `up1_cell_log` 제외) + 기작 9열. 약화 기본 열은 지점 범주 `basin`·`facility_type`, 지점 임계 수온 편차 `wtemp_minus_site_thresh`, 4주 최대 `cell_max_4w`, `cell_log_lag1w`·`cell_log_lag3w` 를 빼고, 상대 열 `cell_max4w_rel` = 4주 최대 − t0, `cell_chg_1w`·`cell_chg_3w` = t0 − 1·3주 전을 넣은 것이다. v1 30열에는 장기 평균 열이 없어서, 약화 대상은 범주와 긴 창 절대 수준 열로 정했다.
- weak0: weak 에서 t0 까지 뺀 진단용 묶음이다.
- 대조군 mechK·weakK: 기작 9열을 같은 결측 위치의 표준정규 난수(`harness2.noise_like`)로 바꾼다.
- C+mech: C 의 수준 타깃 구성원(속별 포함)에 기작 9열을 넣는다. 대조군은 C+mechK 다.
- K5: PREREG_FINAL 의 '새 피처 없는 후보' 대조군(C + 난수 5열)이다. base 후보의 대조군으로 보고만 한다.
- 분해 lvl: 같은 모델 종류를 수준 타깃으로 학습해 같은 방식으로 더한다. 구성원이 하나 늘어난 효과와 변화량 타깃의 효과를 나눠 보기 위한 것이다.

**성장 기작 피처(`make_mech_features`, as_of 순수 함수).** 원자료는 일 단위 달력 `data/interim/daily_<지점>_S1.parquet`(읽기 전용, S1 = 측정값 전진 채움)이다. 읽는 즉시 2025-12-31 이후 행을 버리고, 함수 진입 직후 `cut_as_of` 를 적용한다. 창은 base_date 를 포함한 7일이다.

- **선택: add_gbm_base_none**. C 의 구성원 c1·c3·c2·cg 에 Δ 타깃 일반 LightGBM 구성원 d 를 더하고, 연도 확장 NNLS 로 결합한다. 피처는 C 와 같고(v1 30 + F2 5), 원단위 복원 보정은 없다(none).

## 9. 한계

- 문헌값의 불확실성: Dolichospermum T_opt(25℃)는 근거가 상대적으로 약하다(3온도 실험 + 리뷰 서술). Q10(2.35)은 Lürling 외(2013)의 두 평균에서 유도한 값이다. 트리 모형은 단조 변환에 둔감하므로 값을 바꿔도 결론은 같을 것으로 본다. GAM 은 스플라인이라 역시 둔감하다.
- 일 수온은 S1(측정값 전진 채움)이라 주 1회 측정 사이의 변화가 없다. 7일 창 성장률은 사실상 마지막 1~2회 측정 수온의 함수다. 일사·일조는 관측소 일자료로 수체 내 광량(탁도·수심)을 반영하지 못한다.
- 희석률은 보 저수량/방류량 기반이다. 하천형 보 구간의 실제 체류시간과 다를 수 있다(v1 의 `weir_residence_proxy` 와 같은 정의의 역수).
- 원단위 복원은 none 과 연도 확장 Duan 두 가지만 봤다. Duan 계수가 약 5 로 너무 커서 결합에서 사실상 쓰이지 않았다. 원단위 MSE 맞춤 계수 같은 복원은 1차 실험(R1)에서 2025 가 나빠진 점예측 축이라 시도하지 않았다.
- 탐색 시드 5개와 후보 36개 중 최대를 고른 값이라 승자 편향이 있다. +0.011 은 시드 잡음 폭(±0.02~0.04) 안이다.
- 약화 버전은 v1 30열에 있는 절대 수준 열만 다뤘다(장기 평균 열은 v1 에 없음). 2025 9~10월 개선(−0.015)은 n = 61 의 작은 표본이다.

## 10. 재사용 API(종합 단계)

```python
from algaecast.exp import harness as H, harness2 as H2
from algaecast.exp import r2nd_p1_change as P

df = H.load_base()
feats = P.Feats(df)                 # F2 5열 + 성장 기작 9열(build_features) + 약화 상대 3열(weak_frame)
out = P.builder(df, seed, feats)    # 선택 설정 점예측 {"pred", "q90": None, "w_d"} — harness2.Builder 형식
mem = P.members(df, seed, feats)    # {"c1","c3","c2","cg"(C 캐시), "d"(Δ gbm, none 복원), "d_log"}
pred, w = H.ensemble_expanding(df, mem, names=("c1", "c3", "c2", "cg", "d"))
mech = P.build_features(df)         # 성장 기작 9열(MECH_COLS, 같은 인덱스) — 선택 설정에는 쓰지 않음
o = P.member_oof(dfx, cols, model, seed, target="delta")   # 임의 구성원 OOF {"lp","none","smear","smear_fac"}
```

- `P.CHOSEN = {"kind": "ens", "form": "add", "model": "gbm", "fs": "base", "bias": "none", "target": "delta"}`.
- 캐시 이름 규칙: 구성원은 `P1_m_<model>_<fs>[_lvl]`, 결합은 `P1_<form>_<model>_<fs>_<bias>[_lvl]`, C 계열은 `P1_Cmech`·`P1_CmechK`·`P1_K5` 이고, 위치는 `data/processed/exp/EXP-005b/cache/<이름>_<seed>.parquet` 다. 판정 시드로 돌리면 같은 이름에 시드 번호만 달라진다.
- 판정 시드 대조군: 선택 설정은 새 피처 열이 없으므로 PREREG_FINAL 의 K_s = C + 난수 5열(`c_extra_builder(feats, "K5")`)이다.

## 3. as_of 누수

### 3.1 코드

- `make_dam_features`·`link_state` 는 진입 직후 `cut_as_of(·, as_of)` 를 부른다. lag 이 있으면 `as_of − lag` 로 한 번 더 자른다(측정·방류 모두).
- 방류 창은 `window_days(r, as_of − lag, 7)` 로 as_of−lag 를 포함한 7일이다. 하류 유량 창은 as_of 를 포함한 7일이다. v1 수문 피처와 같은 관례다.
- `build_variant_features` 는 [기준일 −120, +30일] 조각을 넘긴다. as_of 이후 행이 일부 넘어가지만 순수 함수 안에서 버려진다.
- 하류 유량 `daily_<지점>_S1` 의 결측 채움은 `past_month_median_fill` 이다. 전진 채움과 직전 연도까지의 같은 달 중앙값만 쓰므로 미래 정보가 없다.

### 3.2 실제 원자료 재계산(`v_leak.py`)

- **A. 독립 재구현.** 행마다 as_of−lag 이후 원자료를 먼저 지우고 계산했다(미래 행을 아예 보지 않음).
  - 저장 피처 `features_lag0_all`·`features_lagtravel_all`·`features_lag0_certain` 의 2,566행 × 5열과 대조했다.
  - 3종 모두 NaN 위치 불일치 0, 최대 절대차 0 이다. 유효 행은 1,571·1,571·1,566 이다.
  - travel 과 lag 0 은 dam_load_log 가 554행에서 실제로 다르다. travel 경로가 작동한다는 뜻이다.
- **B. 미래 행 교란.** 연결 지점(CS·MGMR·DCHN) 표본 44행(2025-12 기준일 포함) × lag0/travel = 88건을 시험했다.
  - 실제 원자료 전체에서 as_of 이후 측정·방류·하류 유량을 난수로 바꾸고 절반을 지웠다.
  - 그 상태로 `P6.make_dam_features` 를 돌린 결과가 저장 피처와 88/88 같았다.
- **C. travel 구간 교란.** lag>0 연결마다 (as_of−lag, as_of] 의 측정을 9e9, 방류를 9e5 로 바꿨다.
  - 26건 모두 travel 결과가 같았다.
  - 같은 교란이 lag 0 결과는 26/26 바꿨다. 즉 시험이 민감하다.
- **테스트.** `tests/test_exp_r2nd_p6_damres.py` 29개 통과(2.4초), 전체 pytest 402개 통과(44.6초).

## 5. 대조군 구현

- `H2.noise_like(X, s)` 는 `RC.control_columns(index, k, s, mask=X.notna(), salt=20261022)` 다. 열 i 는 X 의 열 i 결측 위치를 그대로 쓴다.
  - 시드 11 load2 에서 열 수 2, 전 행(2020 이전 학습 행 포함) 결측 위치 일치를 확인했다.
  - 전 구성 재학습 스크립트에서도 변형·시드마다 열 수·결측 위치 일치를 assert 했다.
- 생성기 (20261022, 시드, 열 수)는 PREREG_FINAL (a) 정의와 같다. 피처가 아닌 구성원 교체는 없다(P6 는 피처만 추가).
- 대조군 열은 새 피처와 같은 자리(R2 5열 뒤)에 붙는다. 열 수가 같으므로 LightGBM 열 표본추출 조건이 같다.
- **대조군끼리 비교.**
  - core4_lag0_all 과 core4_travel_all 은 결측 위치가 같다(둘 다 유효 1,571행). 그래서 난수와 대조군 결과가 같다. 정상이다.
  - core4_lag0_certain 은 5행(칠서, 영천 방류 결측 2019-01~02)에서 결측 위치가 다르다. 시드별 대조군 값이 −0.010~+0.014 다르다. README 3절 설명과 맞다.

## 8. 사소한 문제(minor, 결론 영향 없음)

1. **'기준 미달' 대체 선택 규칙 문구.** EXP-PLAN 4절은 "만족 변형이 없으면 CV r2_raw 최대"다. P6 `choose()` 는 "고유 효과 최대"다. 2차 문서(PREREG_FINAL)에는 대체 규칙이 없다. 이번에는 두 규칙 모두 `load2_lag0_all` 이라 영향이 없다.

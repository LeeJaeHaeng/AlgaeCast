## 7. 발견 사항(모두 경미, 결론 불변)

### 7.1 A2·B 대조군이 PREREG_FINAL 의 K_s 정의와 다르다 — `d_vs_control` 의 뜻이 다름

PREREG 는 후보의 새 피처 열을 같은 결측 위치의 난수로 바꾸고, 피처가 아닌 구성원은 그대로 둔다. 새 피처 열이 없으면 K_s = C + 표준정규 난수 5열이다. P5 는 A2 를 무작위 국면 표지 게이트와, B 를 무작위 이웃 kNN 과 비교했다. 실행자 보고의 `d_vs_control` 0.0094 와 `explore_check.d_vs_ctrl` 은 이 구조 대조군 기준이고 PREREG K_s 가 아니다.

PREREG 정의로 다시 계산했다(P1 캐시 `P1_K5` = C + 난수 5열, 탐색 시드).

| 비교 | 시드 평균 CV r2_raw 차이 |
|---|---|
| A2 − K(K5 구성원에 게이트 유지) | +0.0192 |
| A2 − K5 | +0.0282 |
| B − K(K5 구성원 + kNN 구성원 유지) | +0.0174 |
| B − K5 | +0.0339 |

어느 쪽도 +0.040 에 못 미치므로 탐색 판정은 그대로다. 종합 단계에서 `d_vs_control` 을 PREREG (a)의 세 번째 조건 값으로 옮겨 쓰면 안 된다.

### 7.2 선택 결과가 대조군 정의에 민감하다

선택 규칙 (iii)(고유 효과 > 0)에 PREREG K 를 쓰면 B 의 고유 효과가 +0.017 > 0 이라 적격이 된다. 그러면 ΔC 가 더 큰 B(k40-site-delta, +0.0148, rmse_log −0.0086)가 A2(+0.0091) 대신 선택된다. 실행자의 구조 대조군이 '유사도' 효과를 따지기에 더 엄격하다는 점은 타당하다. 다만 A2 와 B 의 차이(0.006)는 시드 잡음(±0.01) 안이고, 선택 설정 A2 는 부트스트랩 구간이 0 을 포함한다. 그래서 `P5.CHOSEN`(A2)을 P5 의 대표 요소로 종합 단계에 넘길 근거는 약하다. 이 점은 실행자 보고와 같은 결론이다. 참고로 B 도 2025 F1@10k −0.026, 1~8월 rmse_log +0.017 로 확인 구간에서는 나쁘다(선택에는 쓰지 않음).

### 7.3 "결과 보기 전 고정" 을 사후 확인할 수 없다

P5 코드·테스트가 git 에 커밋되지 않았다. 국면 문턱(0.3·2.0·3.0), 게이트 최소 행 50, kNN 거리 가중치·벌점, 선택 규칙 (i)~(iii) 이 실행 전에 정해졌는지는 시점 증거가 없다. 로그로는 두 실행의 결과가 같다는 것만 확인된다.

### 7.4 A2 의 CV 이득은 통합 지표에서만 나타난다

통합 CV r2_raw 는 +0.009 지만, CV 폴드 평균 r2_raw 는 C 보다 −0.021(0.231 vs 0.252) 낮다. 연도별로 2021 −0.104, 2023 −0.045 로 5개 폴드 중 2개에서 크게 나쁘다. 이득은 SST 가 큰 2024(+0.040)에서만 온다. 보고서는 연도별 차이를 적었지만 폴드 평균 감소는 적지 않았다.

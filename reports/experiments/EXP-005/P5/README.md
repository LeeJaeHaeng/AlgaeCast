## 1. 목적·설정

**사용자 지시 원문.**
- 국면 분류(평온/증가/정점/감소) + 국면별 회귀(mixture of experts).
- 아날로그 kNN 구성원: 지점·계절·최근 3회 궤적·수온·체류시간 유사도, k는 CV로.
- 전년도 최고치, 올해 누적 강도 대비 평년 피처.
- 메모: 국면 정의는 as_of 까지의 측정만으로(규칙 기반 또는 학습 구간에서 적합). kNN 은 각 폴드의 학습 행(기준일 연도 < 검증 연도)만 이웃 후보로 쓰고, 이웃의 미래(목표) 값으로 예측. '평년'은 학습 구간 연도만으로 계산(검증 연도 제외). 구성원은 C 의 NNLS 에 추가해 비교.

**기준 모델·평가.** C = v1 로그 앙상블(C1·C3·C2) + R2 상류 피처 5열 + R3 속별 구성원 cg, 결합은 연도 확장 NNLS(log 공간), 분위는 v1 동결 q90(`q90=None`) — 모든 변형의 리드타임은 18/20 으로 같다. 탐색 시드 (11, 22, 33, 44, 55), 판정 시드는 쓰지 않았다. C 탐색 시드 결과는 `harness2.baseline_c` 캐시(BASE_C.md 와 같은 값). 표는 `harness2.table2`, 구간은 CV 2020~2024·2025 전체·2025 1~8월(옛 위치)·9~10월(새 위치), 2025 는 목표일 ≤ 2025-12-31 행(252행)만. 하이퍼파라미터는 v1(`harness.v1_specs`) 그대로다.

**원자료.** 조류경보 원자료 5지점 `data/raw/nier_algae/nier_algae_2012_2026.parquet`(`r2_upstream.load_algae` — 2025-12-31 이후 측정은 읽은 즉시 버림)와 v1 피처(`harness.load_base`)만 썼다. 새 수집·새 원자료는 없다(MANIFEST·데이터 명세 조각 없음).

### 1.2 B. 아날로그 kNN 구성원

- 이웃 후보 = 그 폴드의 학습 행(기준일 연도 < 검증 연도, v1 폴드와 같은 규칙). 예측은 이웃의 목표값으로만 한다.
- 거리: 최근 3회 궤적(L0·L1·L2)·계절(기준일 doy sin·cos, 각 가중 0.5)·수온(`wtemp_t0`)·체류시간(log1p `weir_residence_proxy`, 지점별 표준화)의 결측 인지 가중 유클리드. 표준화 통계는 후보 행으로만 낸다.
- 지점: site = 같은 지점 우선(같은 지점 후보가 k 보다 적을 때만 다른 지점, 예: 2020 물금·매리), all = 다른 지점에 거리 벌점 2.0.
- 집계: log = 이웃 목표 log10 평균, raw = 원단위 평균, delta = 자기 L0 + 이웃(목표 log − 이웃 L0) 평균.
- 격자 k ∈ {5, 10, 20, 40} × 지점 2 × 집계 3 = 24개 → C + kNN NNLS 의 시드 평균 CV r2_raw 최대를 고른다. 대조군 = 같은 풀에서 무작위 k 이웃(같은 집계).

### 1.3 C. 전년도·평년 대비 피처(순수 함수 `history_features`, 진입 직후 `cut_as_of`)

| 열 | 정의 |
|---|---|
| hy_prev_max | 기준일 전년도 측정의 최고 log10(세포수+1) |
| hy_ytd_mean | 올해 1/1(또는 첫 측정)~as_of 일 단위 이월(ffill) log10 세포수의 평균 = 누적 강도 |
| hy_ytd_max | 같은 구간 최고 |
| hy_ytd_mean_anom·hy_ytd_max_anom | 과거 연도(기준일 연도보다 앞, 그해 1/1 + 31일 안에 측정 시작)의 같은 날짜까지 값의 평균 대비 차이. 2년 이상일 때만 |

평년은 기준일 연도보다 앞선 연도만 쓰므로 어느 폴드에서도 검증 연도가 섞이지 않는다(검증 연도 Y 행의 평년 ⊂ 학습 연도 < Y). 변형 H1(hy_prev_max 1열)·H2(올해 4열)·H3(5열)을 C 의 회귀 구성원 피처에 추가했고, 각각 같은 열 수·같은 결측 위치의 난수 대조군을 같은 구조로 돌렸다.

### 1.4 선택 규칙(CV 만, 실행 전 고정 — 코드 docstring)

시드 평균 ΔC CV r2_raw 최대, 단 (i) ΔC CV rmse_log ≤ +0.01, (ii) 리드타임 시드 평균 ≥ 18, (iii) 고유 효과 Δ − Δ(대조군) > 0. 적격 변형이 없으면 C 유지. 이어 다른 갈래의 최고 적격 변형을 하나씩 더해 시드 평균 CV r2_raw 가 +0.01 이상 오르면 결합한다. 이번에는 적격 변형(A1·A2·A4)이 모두 A 갈래라 결합 단계가 없었다.

### 5.5 전년도·평년 피처가 해로운 이유(추정)

- 같은 열 수의 난수 대조군도 −0.002(1열)·−0.023(4열)·−0.034(5열)로 떨어진다. C 위에 열을 더하는 것만으로도 CV 원단위 R² 가 흔들린다(1차에서는 v1 + 난수 열이 +0.035~+0.051 이었다 — 방향이 정해지지 않은 잡음).
- 고유 효과도 −0.011~−0.019 다. 올해 누적·평년 대비는 한 해 동안 천천히 변하는 연도 수준 값이라 트리가 '연도 구분자'처럼 써서 다른 해로 일반화가 나빠진 것으로 보인다(연도별: H3 는 2022 −0.048, 2024 −0.084).
- 2025 에서는 H2·H3 가 r2_raw +0.010·+0.015, rmse_log −0.007·−0.008, 9~10월 rmse_log −0.013 으로 C 보다 낫다. 하지만 F1@10k −0.04 이고, 선택은 CV 만으로 하므로 채택 근거가 아니다.

## 6. 선택한 변형과 이유

- 규칙(1.4)에 따라 **A2 국면별 NNLS 게이트**(`P5Config(gate=True)`, 캐시 `P5_gate`)를 P5 선택 설정으로 고정했다(`CHOSEN`). 적격 변형 A1(+0.001)·A2(+0.009)·A4(+0.001) 중 ΔC 최대다. 적격 변형이 모두 같은 갈래라 결합 단계는 없었다.
- 선택 설정의 시드 짝 차이: CV r2_raw +0.0091, CV rmse_log +0.0004, 2025 r2_raw −0.0273, 2025 rmse_log +0.0043, 2025 1~8월 rmse_log +0.0063, 9~10월 rmse_log +0.0035, 2025 F1@10k −0.0154. 블록 부트스트랩(연도·지점 25블록, 2,000회, 생성기 20261022) CV r2_raw 차이 95% [−0.020, +0.026], 중앙값 +0.008.
- 판단: 선택은 규칙대로지만 효과 크기가 잡음 폭 안이고 2025 확인에서 나빠진다. **P5 는 원단위 R² 고도화에 쓸 만한 구성 요소를 찾지 못했다**고 보는 것이 맞다. 종합 단계에 넣을지는 메인 세션이 정한다.

## 9. 한계

- 국면 문턱(0.3·2.0·3.0)은 실행 전 고정했고 조정하지 않았다. 다른 문턱이나 학습 구간에서 적합한 국면(군집 등)은 시험하지 않았다.
- kNN 거리 가중치(궤적 3·계절 1·수온 1·체류 1)와 지점 벌점은 고정값이다. k·지점·집계 24칸을 CV 로 고른 것도 선택 잡음(승자의 저주)을 안고 있다. 다만 최고 칸도 무작위 이웃 대조군보다 낮아 결론은 바뀌지 않는다.
- 전문가는 C1(v1 log_w) 하나만 국면별로 학습했다(C3·C2·속별은 공통). 하이퍼파라미터는 v1 그대로라 작은 국면 표본에 맞지 않을 수 있다.
- 탐색 시드 5개 평균이라도 CV r2_raw 짝 차이의 잡음은 ±0.01 수준이다. 블록 부트스트랩도 A2 의 구간이 0 을 포함한다.
- NNLS 는 로그 공간에서 적합하므로 원단위 R² 를 직접 겨냥하지 않는다(지시대로 C 의 NNLS 에 추가해 비교했다).

## 10. 재사용 API(종합 단계)

```python
from algaecast.exp import r2nd_p5_regime_analog as P5

P5.build_features(df)          # 선택 설정의 새 피처 열 → 열 0개(A2 는 피처 없음), 같은 인덱스
P5.members(df, seed)           # 선택 설정의 OOF 구성원 {c1, c3, c2, cg}(= C 구성원, 캐시)
P5.builder(df, seed)           # harness2.Builder: {"pred", "q90": None, "m_c1"...} — 국면별 NNLS 게이트 결합
P5.regime_groups(df)           # 국면 코드(0 평온·1 증가·2 정점·3 감소), as_of 규칙
P5.gated_ensemble(df, members, P5.regime_groups(df), names=("c1", "c3", "c2", "cg"))  # 다른 구성원 묶음에도 게이트 적용
P5.make_builder(P5.P5Config(knn=P5.KnnCfg(40, "site", "delta")))  # 임의 설정(knn·experts·feats·gate, ctrl=True 는 대조군)
P5.knn_member(df, P5.build_state(df), P5.KnnCfg(40, "site", "delta"))  # kNN 구성원 단독
P5.state_features(algae_site, as_of) / P5.history_features(algae_site, as_of)  # 순수 함수
```

df 는 `harness.load_base()` 형식이다. 결합 단계에서 다른 구성원(예: 새 피처로 다시 학습한 c1·c3·c2·cg)에 게이트를 걸려면 `gated_ensemble` 에 그 구성원을 넘긴다.

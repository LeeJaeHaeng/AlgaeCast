## 2. 운영 정의(실행 전 확정)

**기준 모델.** C(EXP-confirm 채택) = v1 로그 앙상블(C1·C3·C2) + R2 상류 피처 5열 + R3 속별 구성원 cg, 분위 모델은 v1 동결본이다(`algaecast.exp.confirm.config_members`, 결합은 `harness.ensemble_expanding(names=("c1","c3","c2","cg"))`).

**시드.**
- 탐색 시드 (11, 22, 33, 44, 55): P1~P6 실험표와 누적 결합 선택에 쓴다.
- 판정 시드 (1001, 2002, 3003, 4004, 5005): 최종 판정에만 쓴다. 최종 후보는 판정 실행 전에 `EXP-005/COMBO/FINAL_CANDIDATE.md` 로 고정해 커밋한다.

**구간.**
- CV = 2020~2024 OOF 통합.
- 2025 = Final 폴드(학습 ≤2024). 보고는 2025 전체, 2025 1~8월, 2025 9~10월로 나눈다(목표일 기준).

**(a)**
- 시드별 Δ_s = r2_raw_CV(후보_s) − r2_raw_CV(C_s). 평균 ≥ +0.080.
- 부트스트랩: (연도·지점) 블록(2020~2024 × 5지점)을 복원추출 2,000회 한다(생성기 20261022). 반복마다 시드별 Δ_s 를 다시 계산해 평균하고, 2.5 백분위수 > 0 이어야 한다.
- 대조군 K_s: 후보에서 2차 실험으로 새로 들어간 피처 열을 모두 같은 결측 위치의 표준정규 난수로 바꾼 구성이다(생성기 (20261022, s, 열 수)). 피처가 아닌 구성원(칼만·아날로그 등)은 그대로 둔다. 후보에 새 피처 열이 없으면 K_s = C + 표준정규 난수 5열이다. 시드 평균 (후보 − K) ≥ +0.040 이어야 한다.

**(b)** 기준값은 같은 판정 시드로 학습한 C_s 의 시드 평균이다. 후보 값도 시드 평균이다.

| 지표 | 조건 |
|---|---|
| 2025 r2_raw | 후보 ≥ C − 0.02 |
| 2025 rmse_log | 후보 ≤ C + 0.01 |
| 2025 F1@10k | 후보 ≥ C − 0.02 |
| 리드타임(q90≥10k, 2020~2025 사건 20건) | 시드 평균 ≥ 18.0 |

**(c)** 2025 9~10월(목표일 기준) rmse_log 의 시드 평균이 후보 ≤ C 여야 한다(허용 오차 없음). P2 보정을 쓰는 후보는 PREREG_P2 의 한 행 빼기 교차 적합 값을 쓴다.

**(d)** 전체 pytest 와 2차 실험에서 추가한 누수 테스트가 모두 통과해야 한다.

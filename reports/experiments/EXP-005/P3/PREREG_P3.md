# 사전등록 — EXP-005 2차 P3: 기상청 단기예보 격자 과거 발표분 피처(재시도)

등록 2026-10-22. 이 문서는 모형을 한 번도 돌리기 전에 커밋한다. 커밋 이후에는 정의·절차·기준을 바꾸지 않는다. 자료 수집(예보값만 받으며 정답값은 쓰지 않음)은 이 문서와 같은 날 진행 중이다. 수집 범위와 결측 구조는 표본 호출로 확인한 사실([`PROBE_GRID.md`](PROBE_GRID.md))에서 정했다.

## 1. 사용자 지시(2026-10-22, 요지는 원문 그대로)

  - 승인 목록: fct_shrt_reg·fct_afs_ds·fct_medm_reg·wrn_reg.

- 이전 지시: "통과하면 최종 모델은 C+P3, 아니면 C."

## 2. 데이터 원천과 지시 대비 범위(표본 호출 사실)

| 지시 항목 | 원천 | 가능 여부 |
|---|---|---|
| 단기 +1~+3일 최고·최저기온 | 격자 TMX(15시)·TMN(06시) | 2016~2025 가능. +3일은 기준일 2021-11-29부터 |
| 단기 강수확률·하늘상태 | 격자 POP·SKY | 기준일 2021-06-30부터. 그 전 발표분은 0채움(실제 값 아님) → 결측 처리 |
| 단기 강수량(가능하면) | 구형 R06(6시간), 신형 PCP(1시간) | 2016~2025 가능. 정의가 둘이라 3절처럼 일 단위로 맞춘다 |
| 중기 +4~+7일 | `fct_medm_reg`는 구역 목록뿐, 자료 경로 `fct_afs_wl`·`fct_afs_wc`는 403 | **불가 → 제외** |
| 특보 폭염·호우 발효 여부·일수 | `wrn_reg`는 구역 목록뿐, 자료 경로 `wrn_met_data`·`wrn_now_data`는 403 | **불가 → 제외** |
| (참고) 단기 개황 `fct_afs_ds` | 문장(예상 강수량 범위 등) | 과거분은 조회되지만 수치 피처를 만들 수 없어 쓰지 않음 |

2016~2025 과거 발표분이 실제로 조회되므로(PROBE_GRID 2절) P3를 실시한다. 범위는 위 표의 가능 항목뿐이다.

## 3. 피처 정의(`algaecast.exp.r2nd_p3_kmafcst`)

**발표분.**
- 5지점 격자 칸(nx, ny)의 기준일 05시 발표분을 쓴다.
- 없으면 issued_at ≤ base_date 05:00 KST이면서 24시간 안의 가장 늦은 발표분(02시, 전날 23·20·17시)을 쓴다.
- 그런 발표분이 없으면 전 열 결측이다.

**목표일.** d = 1, 2, 3 (기준일 + d일).

**변수**(열 이름 `p3_fc_<변수>_d<d>`, 5변수 × 3일 = 15열):

| 변수 | 정의 |
|---|---|
| ta_max | 그날 TMX(15시 발효) |
| ta_min | 그날 TMN(06시 발효) |
| pop_max | 그날 09·15·21시 POP의 최대 |
| sky_mean | 그날 09·15·21시 SKY의 평균(1 맑음 · 3 구름많음 · 4 흐림) |
| rn_day | 구형: 그날 6시간 R06 4개(00~06·06~12·12~18·18~24) 합, 하나라도 없으면 결측. 신형: 그날 09·15·21시 PCP 평균 × 24(일 환산 mm), 셋 중 하나라도 없으면 결측 |

**점검용 메타 열**(모형 입력 아님): `p3_fc_issue_lag_h`(05시 기준 지연 시간), `p3_fc_available`.

**결측 처리 규칙**(`calls_to_long`):
- TMX·TMN·SKY는 육지 격자 전체가 0이면(0채움) 버린다.
- POP·PCP는 같은 발표·발효 시각의 SKY가 정상일 때만 쓴다.
- R06은 전국 0도 쓴다(실제 무강수일 수 있음).
- 지점 값 ≤ −90은 결측이다.
- 모형에는 결측(NaN) 그대로 넣는다(LightGBM 결측 처리). 대치하지 않는다.

**범위 밖 결측.** 다음 행은 모든 P3 열이 결측이다.
- 기준일 2012~2015 행: 지시 범위 밖이라 수집하지 않았다.
- 발표분이 없는 기준일 8개.

**누수 규칙**(테스트 `tests/test_exp_r2nd_p3_kmafcst.py`로 고정):
- `forecast_features`는 진입 직후 `cut_as_of(issued_at)`을 거친다.
- 이어서 `issued_at ≤ base_date 05:00`으로 자른다.
- 테스트는 그 뒤 발표분(같은 날 08시 이후 포함)을 난수로 바꾸거나 지워도 결과가 같은지 구형·신형 모양 모두로 확인한다.
- 수집기는 발표시각을 항상 기준일 05시 이하로만 요청한다(`FALLBACK_HOURS` 테스트).

## 4. 실험 절차(`algaecast.exp.r2nd_p3_run`)

**기준 모델.** C(PREREG_FINAL 2절과 같음)다. 후보는 C의 피처(v1 30 + 상류 5)에 P3 묶음 열을 더해 C 구성원 4개(c1·c3·c2·cg)를 다시 학습한다. 결합 방식(연도 확장 NNLS)과 분위(v1 동결)는 그대로다.

**묶음**(중첩, 사전 고정):
- T = ta_max·ta_min × d1~d3 (6열)
- TS = T + pop_max·sky_mean (12열)
- TSR = TS + rn_day (15열)

**탐색.**
- 탐색 시드 (11, 22, 33, 44, 55)로 묶음마다 후보와 그 난수 대조군을 평가한다. 대조군은 같은 결측 위치의 표준정규 난수다(`harness2.noise_like`).
- 시드 평균 ΔCV r2_raw(대 C)가 가장 큰 묶음 하나를 고른다. 차이가 0.002 미만이면 열이 적은 묶음을 고른다.
- 탐색 결과와 상관없이 고른 묶음 하나를 판정에 올린다. 판정에 오르는 후보는 하나뿐이다.

**판정.**
- 판정 시드 (1001, 2002, 3003, 4004, 5005)로 C_s, 후보(C + 고른 묶음), K_s를 학습한다.
- K_s는 후보의 P3 열을 같은 결측 위치의 표준정규 난수로 바꾼 것이다. 생성기는 (20261022, s, 열 수)다.
- 아래 기준을 PREREG_FINAL과 똑같이 적용한다.

| 기준 | 조건 |
|---|---|
| a1 | 시드 평균 (후보 − C) CV r2_raw ≥ +0.08 |
| a2 | (연도·지점) 블록 부트스트랩 2,000회(생성기 20261022) 95% 하한 > 0 |
| a3 | 시드 평균 (후보 − K) ≥ +0.04 |
| b1 | 2025 r2_raw ≥ C − 0.02 |
| b2 | 2025 rmse_log ≤ C + 0.01 |
| b3 | 2025 F1@10k ≥ C − 0.02 |
| b4 | 리드타임 포착 시드 평균 ≥ 18 |
| c | 2025 9~10월 rmse_log ≤ C(허용 오차 없음) |
| d | 전체 pytest와 P3 누수 테스트 모두 통과 |

- b·c의 기준값은 같은 판정 시드 C_s의 시드 평균이다.
- 2025 지표는 목표일 ≤ 2025-12-31인 252행만 쓴다(PREREG_FINAL 3절).
- 2025는 판정 확인에만 쓰고 선택에는 쓰지 않는다. 2026은 계산하지 않는다.

**결정.**
- (a)~(d)를 모두 충족하면 'P3 통과' → 최종 모델 C+P3.
- 하나라도 못 미치면 'P3 미통과' → 최종 모델 C.
- 2026-10-23 12:00 KST까지 판정이 나지 않으면 'P3 미실시' → C.

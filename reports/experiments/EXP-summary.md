# 원단위 R²·NSE 고도화 실험 종합 (EXP-004~011)

작성 2026-10-22. 계획·원칙: `EXP-PLAN.md`. 기준선: `EXP-baseline/`. 실험별 상세·검증: `EXP-004/`~`EXP-011/`(각 `README.md`·`VERIFY.md`).
v1 제출본(태그 `v1-submission`, 동결 모델 13ac483, submission.csv sha256 182f4cb8…)은 그대로다. **v2 채택·재동결·제출 교체는 사용자가 정한다. 이 문서 작성 후 실험을 멈춘다.**

## 1. 결론

1. 채택 기준(CV r2_raw +0.10 이상, CV rmse_log 악화 0.01 이내, 리드타임 포착 수 감소 없음)을 **절차대로 통과한 v2 후보는 하나 있다**: v1 + 낙동강·금강 지점 통합 학습(T5) + C1 smearing 단독 점예측(P2). 시드 3개 평균 CV r2_raw 0.348(v1 0.198, +0.150), rmse_log +0.008, 리드 19/20.
2. 그러나 이 후보는 **견고하지 않다.** 2025 확인 r2_raw −0.220(v1 0.166)으로 나빠지고, 이득의 약 68%가 새 정보가 아니라 점예측 방식 전환(로그 공간 NNLS → 원단위 맞춤 단일 모델)에서 나온다. 연도 블록 부트스트랩 95% 구간은 0 을 포함하고, CV 폴드 평균 이득은 +0.043뿐이다.
3. **견고성 대안**은 상류 지점 피처(F2) + 속별 모델 NNLS 구성원(M3), 점예측은 v1 과 같은 로그 NNLS(P0)다. 시드 평균 CV r2_raw 0.315(+0.117), rmse_log −0.010, 2025 0.168(v1 수준 유지)이다. 다만 분위 모델을 v1 으로 고정한 진단 경로에서 나온 구성이다. 정식 절차에서는 분위를 다시 학습하면 리드타임이 줄어 탈락했다.
4. 영양염(R4)·자동측정망(R6)·희소 사건 가중(R7)은 효과가 없거나 난수 대조군과 구분되지 않았다.
5. 참가신청서 목표 **원단위 R² 0.6·NSE 0.5 와는 여전히 거리가 멀다.** 이번 실험의 최고치도 CV 0.35, 2025 0.18 수준이다. 원단위 지표는 극소수 봉우리가 좌우한다(2025 최대 관측 1건 = 분산의 43%).

## 4. 공통 발견

1. **CV r2_raw 의 잡음 폭.** 시드만 바꿔도 v1 이 0.173~0.212 로 움직인다. 관측과 무관한 난수 열 3~10개를 더해도 +0.035~+0.051 이 나온다. 단일 시드에서 +0.05 미만의 차이는 판정할 수 없다. 채택 문턱 +0.10 근처의 결과(R2 +0.102)도 경계선으로 봐야 한다.
2. **원단위 R² 이득의 큰 몫은 점예측 방식에서 나온다.** v1 앙상블은 로그 공간 NNLS 로 결합해 봉우리를 낮게 예측한다. C1 smearing 단독이나 원단위 결합으로 바꾸면 CV 원단위 R² 는 오르지만 2025 에서는 과대예측이 늘어 오히려 나빠진다. 이 축의 CV 이득은 2020~2024 의 극단값 몇 행에 기대고 있다.
3. **새 정보 가운데 효과가 보인 것은 '같은 시기 유역 전체의 대발생 상태'다.** 상류 지점 피처(F2)와 다른 지점 통합 학습(T5)이 여기에 해당하고, 둘은 상당 부분 겹친다. T5 위에서 F2 의 증가는 +0.093 에서 +0.020 으로 줄었다. 상류 피처는 고유 효과(대조군 차감 +0.080)가 가장 분명했다. 다만 분위 모델에 넣으면 q90 경보가 흔들려 리드타임이 시드별 18/16/15 로 줄었다.
4. **영양염·자동측정망·희소 가중은 효과가 없었다.** 영양염은 대조군과 구분되지 않았고(공개 지연 약 55일), 자동측정망 7일 추세는 시드 평균 −0.018 이었다. 희소 사건 재표본·가중은 30개 변형 모두 +0.003 이하였다.
5. **2025 는 v1 이 이미 상위권이다.** 2025 r2_raw 가 v1(0.166)보다 확실히 높은 구성은 없다. 가장 높은 값도 R6 0.183, 견고성 대안 0.177 수준이라 잡음 폭 안이다.

메인 세션 의견: B 는 2025 확인에서 v1 보다 나빠지므로 제출 교체 근거로 약하다. C 는 2025 를 유지하면서 CV 를 올리고 운영 부담이 없다. 다만 선택 절차 밖에서 나왔으므로, 채택하려면 같은 원칙으로 확인 실험을 한 번 더 하는 것이 맞다. 확인 실험은 분위 v1 고정을 사전에 규칙으로 정하고 다른 시드를 쓰는 방식이다. 원단위 R² 0.6 목표는 어느 선택지로도 닿지 않는다. 따라서 방법설명서의 현재 서술(원단위 지표는 봉우리 높이 재현을 측정하고, 운영 목적에는 로그 R² 와 경보 F1 이 부합한다)은 유지하는 편이 맞다.

v2 를 채택하면 필요한 후속 작업: 재동결(새 FROZEN.md·해시), 일일 파이프라인 반영(F2 는 기존 수집 자료로 가능, T5 는 재학습 때만 전국 자료 필요), 2026 사후 검증(채택 후에만 계산), 방법설명서·대시보드 수치 갱신, 제출 패키지 재빌드·재현 검증.

비교 시 주의:
- 인용 문구: **Kim·Shin·Cha(2023): 7·14일 예측 R² 0.35~0.50(척도는 원문 확인 필요).** 초록상 이 범위는 7일과 14일을 합친 값이고, 로그 척도인지 원단위인지는 확인되지 않았다(원문 페이지 접근 차단). 본문 표를 확인하기 전에는 로그 R² 로 단정하지 않는다.
- 주 1회 측정을 일 단위로 채운 뒤 1일 선행을 예측하면 지속성 때문에 R² 가 0.98 대로 부풀려진다. 우리 7일 선행과 맞는 비교 대상은 7일·1주 선행 값이다.
- 무작위 분할(70/30, 50/50)은 시계열 자기상관 때문에 낙관적으로 나온다. 시간 순서 홀드아웃은 국립환경과학원 2023(1지점·2022년 1년) 정도다. 우리 연도 확장 CV + 2025 홀드아웃이 더 엄격하다.
- 1주·7일 선행 R² 는 문헌마다 0.35~0.93 으로 넓게 흩어져 있고, 척도·타깃·분할 방식이 서로 다르다. 척도가 확인된 것과 비교하면, 우리 로그 R² 0.71~0.78 은 대청호 Chl-a 1주(0.63~0.77, 무작위 분할)와 비슷하고, 국립환경과학원 2023(1지점·1주·log10·2022 홀드아웃, 0.93)보다 낮다. Kim·Shin·Cha(2023)의 7·14일 R² 0.35~0.50 은 척도가 확인되지 않아 우리 값과 직접 비교하지 않는다. 원단위 R² 0.17~0.30 은 원단위 Chl-a 연구(0.43~0.46)보다 낮다. 다만 그 연구는 타깃과 분할 방식이 다르다.

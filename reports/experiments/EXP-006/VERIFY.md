## 2. CV 전용 선택 — 통과

- 변형 선택은 `adoption`(CV 지표만 사용)을 통과한 변형 중 `cv_r2_raw` 최대로 한다.

  - smearing 은 폴드마다 학습 잔차로 계산한다(`fit_predict`·`_hurdle_fit`).
  - NNLS 가중은 `harness.ensemble_expanding` 이 연도 확장으로 적합한다.

  - Microcystis 부분의 2023 이후 라벨을 난수로 바꿨다.
  - 2020~2023 OOF 는 그대로였다(smear·none 둘 다). 2024·2025 OOF 는 바뀌었다.
  - 즉 학습에는 기준일 연도 < 검증 연도인 라벨만 쓰인다.
- 참고: `select_modes`(부분별 log/hurdle 선택)는 연도 확장이 아니다.
  - 2020~2024 OOF 전체로 한 번 고르므로 '속별 선택' 변형의 CV 수치는 약간 낙관적이다.
  - 선택된 G2 변형에는 영향이 없다. G2 의 속별 선택 결과가 log/log 라 같은 변형으로 합쳐졌다.

## 남는 문제(위반 아님)

1. **major — 채택 통과가 약하다.**
   - 통합 CV Δr2_raw 는 +0.131 이다. 그러나 폴드 평균 Δ 는 +0.008 이다.
   - 블록 부트스트랩 95% 구간은 [-0.005, +0.168] 로 0 을 포함한다.
   - 2021 r2_raw 는 0.102 로, v1 0.328 보다 크게 낮다.
   - 2025 r2_raw 는 0.161 로 v1 0.166 보다 낮고, rmse_log 는 0.731 로 v1 0.708 보다 나쁘다.
   - 채택 기준은 문자 그대로 만족하지만 일반화 근거는 약하다.
2. **major — R3 의 핵심 가설(속별 분해)은 원단위 R² 에 기여하지 않는다.**
   - 선택 − C1 합계 단독: Δr2_raw −0.003 [95% −0.073, +0.022].
   - 분해의 실제 효과는 rmse_log −0.008 [95% −0.024, +0.006] 이다. 이 차이 덕분에 rmse_log 기준(0.01)을 넘은 것이다(C1 단독 +0.013 → 선택 +0.006).
   - 이득의 대부분은 '앙상블 → smearing 단독 점예측' 전환에서 온다. 이 부분은 R1(EXP-004)과 겹친다.
   - 종합(EXP-011)에서 R1 과 R3 의 이득을 따로 셈하면 같은 이득을 두 번 세게 된다.
3. **minor** — 2025 를 근거로 쓴 대목이 있다.
   - README '다음 단계'는 c1→cg NNLS 대안이 "2025 에서도 v1 보다 조금 나아 더 안정적"이라고 쓴다.
   - 종합 단계에서는 두 후보(단독 / NNLS 구성원)를 CV 로만 골라야 한다.
4. **minor** — `select_modes` 는 2020~2024 OOF 전체로 부분 방식을 한 번 고른다(연도 확장 아님). '속별 선택' 변형 수치가 약간 낙관적이지만, 선택 결과에는 영향이 없다.
5. **minor** — 선택 변형과 차점 변형의 차이가 작다.
   - G2(0.3034)와 G4(0.2986)의 CV r2_raw 차이는 0.005 로 잡음 수준이다.
   - 시드는 42 하나만 썼고, C1 하이퍼파라미터를 속별 타깃에 재튜닝 없이 썼다(보고서에 적혀 있음).
6. **minor** — 2025 확인 256행 중 4행의 target_date 는 2026-01-05 이다. harness 규약상 허용이고 모든 실험에 공통이다. 위반은 아니지만 투명성을 위해 적어 둔다.

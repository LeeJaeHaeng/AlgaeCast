## 3. S 모델 정의

- v2.1 과 **모두 같게** 둔다: 학습 표본(기준일·목표일 조합, 분할), 피처 목록(35개 = 선별 30 + 상류 5), 하이퍼파라미터, 구성원(c1·c3·c2·cg)과 결합(log10 NNLS, 2020~2024 CV OOF), 학습 기간(최종 ≤2025), 시드 42, 분류기·분위 재적합 규칙, 분류기 임계(CV OOF F1 최대), 운영점(r=3 기대비용 최소), CQR(2023~2024 OOF), 폴드별 학습기간 수온 임계.
- 바꾸는 것은 하나뿐이다: **모든 자료(조류·수질·수문·기상·외부)의 as_of 를 '기준일 전날(base_date − 1일)'로** 둔다. 피처는 기준일 전날까지의 자료로만 계산한다(상류 지점 조류 포함). 달력·지점 상수 피처(월·연중일·지점 정보)는 자료가 아니므로 기준일 그대로 둔다.
- 튜닝·피처 추가·삭제는 하지 않는다.
- 구현: `config/features.yaml` 의 `as_of_offset_days`(기본 0)를 피처 생성(`features.run`)과 상류 피처(`features.upstream`)가 읽는다. 오프셋이 0 이 아니면 피처 파일 이름에 오프셋을 붙인다(`features_S1_asofm1.parquet`). 코드에는 이 인자만 더하고, 기본값 0 에서 v2.1 피처·submission.csv 가 바이트 단위로 같은지 먼저 확인한다.
- 실행: 저장소 사본(작업 폴더)에서 오프셋 1 로 v2.1 과 같은 명령 순서(정렬 → 피처 → `models.alert --skip-tune` → `eval.transitions` → `freeze_v21 --oof` → `freeze_v21 --freeze`)를 돌린다. 저장소의 v2.1 모델·레지스트리·피처·OOF 캐시·config 는 건드리지 않는다.

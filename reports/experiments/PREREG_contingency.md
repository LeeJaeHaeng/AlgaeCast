## 3. S 모델 정의

- v2.1 과 **모두 같게** 둔다: 학습 표본(기준일·목표일 조합, 분할), 피처 목록(35개 = 선별 30 + 상류 5), 하이퍼파라미터, 구성원(c1·c3·c2·cg)과 결합(log10 NNLS, 2020~2024 CV OOF), 학습 기간(최종 ≤2025), 시드 42, 분류기·분위 재적합 규칙, 분류기 임계(CV OOF F1 최대), 운영점(r=3 기대비용 최소), CQR(2023~2024 OOF), 폴드별 학습기간 수온 임계.
- 바꾸는 것은 하나뿐이다: **모든 자료(조류·수질·수문·기상·외부)의 as_of 를 '기준일 전날(base_date − 1일)'로** 둔다. 피처는 기준일 전날까지의 자료로만 계산한다(상류 지점 조류 포함). 달력·지점 상수 피처(월·연중일·지점 정보)는 자료가 아니므로 기준일 그대로 둔다.
- 튜닝·피처 추가·삭제는 하지 않는다.
- 구현: `config/features.yaml` 의 `as_of_offset_days`(기본 0)를 피처 생성(`features.run`)과 상류 피처(`features.upstream`)가 읽는다. 오프셋이 0 이 아니면 피처 파일 이름에 오프셋을 붙인다(`features_S1_asofm1.parquet`). 코드에는 이 인자만 더하고, 기본값 0 에서 v2.1 피처·submission.csv 가 바이트 단위로 같은지 먼저 확인한다.
- 실행: 저장소 사본(작업 폴더)에서 오프셋 1 로 v2.1 과 같은 명령 순서(정렬 → 피처 → `models.alert --skip-tune` → `eval.transitions` → `freeze_v21 --oof` → `freeze_v21 --freeze`)를 돌린다. 저장소의 v2.1 모델·레지스트리·피처·OOF 캐시·config 는 건드리지 않는다.

### 6.3 결론

- **v1-fix 는 번들 외 조류경보 자료(값)를 쓰지 않는다 — 2절 전환 조건 확인.** 조류·수질 피처 12개(#1·2·3·4·6·9·11·16·20·21·22·28)·horizon_days·학습 타깃은 코드에서 API parquet 을 읽지만, 학습 행과 제출 test 124행에 들어가는 값은 번들과 같다(번들로 바꿔 다시 계산한 2,690행의 30개 피처·target_date·학습 타깃 일치, 수온 임계 2019~2025 일치). API 에만 있는 자료(2026-09-14~10-15 의 40행, 2026-09-10 '분석중' 대체값)는 어떤 학습·제출 피처에도 들어가지 않는다.
- **같은 사실이 v2.1 에도 성립한다.** 상류 5열의 '다른 지점 세포수'는 번들 안 지점(해평·강정·고령·칠서)의 값이고, 속별 타깃도 번들 4속 열과 같다.
- 형식까지 번들로 맞추려면 정렬·상수·상류·속별 원천 4곳을 번들 CSV 로 바꿔야 하고, 제출 패키지에 API parquet(번들 밖 40행 포함)이 들어 있다(`scripts/build_submission_package.py`). 피처가 같으므로 submission.csv 도 같을 것으로 보이나 다시 만들어 대조하지는 않았다(확인 못 함). **2026-10-26 추가:** 패키지 재현 경로의 조류 원천을 대회 번들로 바꿔(`collect/algae_source.py`, `algae_source: auto`) 새 가상환경에서 재현한 결과 `submission.csv` 가 바이트 단위로 같았고(sha256 `4741a3d3…`), train·valid·test 행의 피처·목표일·학습 타깃 불일치 0 이었다. 패키지에서 API parquet 은 뺐다(상류 바로 위 지점도 5지점 안이라 남는 행이 없음).
- 참고: 조류경보가 아닌 번들 외 자료(보 운영 K-water·WAMIS, 댐 저수율, DataON·WAMIS 연속 수위, ASOS 288 밀양·131 청주 — 번들 asos_daily 6개소 밖)는 v1-fix·v2.1 모두 쓴다. 대시보드 일일 운영 예측은 조류경보 API 를 실시간 수집한다(제출 모델 입력이 아님). 2026 사후 관심(1천) 사건 7건 중 2건(해평 D 2026-09-14, 강정·고령 E 2026-09-21·D 09-28)과 EDA 3장 통계(2,979건, ~2026-10-15)는 번들 밖 측정을 쓴다.

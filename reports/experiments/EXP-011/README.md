### 1.3 평가 프로토콜(이 실험 전용)

- 시드 S = (42, 7, 2026). 구성마다 시드별로 회귀 구성원(C1·C3·C2, M3 이면 속별 2부분)과 분위(q10·q50·q90; `quantile.fit_quantiles` 에 seed 를 넘기는 자체 루프, T5 는 `r5_national.fold_members(seed=...)`)를 학습하고 시드별 `harness.metric_row` 를 구한다.
- 보고: (a) 시드 42 표준 표(R1~R7 표와 직접 비교), (b) 시드 평균·최소·최대, (c) v1 대비 시드별 짝 차이의 평균 Δ.
- 피처 요소(F2·F4) 대조군: 같은 개수의 표준정규 난수 열(생성기 시드 = (20261022, 학습 시드, 열 수) → 시드마다 다른 난수 3벌)을 **현재 구성 위에** 더해 같은 방식으로 학습한다. 고유 효과 = Δ(피처) − Δ(대조군)(둘 다 현재 구성 대비 시드 짝 차이 평균). T5 위에서는 새 열·난수 열 모두 다른 지점 행에서 NaN 이다.
- 전진 선택(CV 만): v1(P0)에서 출발. 각 단계에서 남은 요소를 하나씩 더해 보고, 시드 평균 CV r2_raw 증가(현재 구성 대비 짝 차이 평균)가 가장 크고 (i) 시드 평균 Δrmse_log(v1 대비) ≤ +0.01, (ii) 시드 평균 리드타임 ≥ v1, (iii) 피처 요소는 고유 효과 > 0 인 후보를 채택한다. 증가가 +0.01 미만이면 멈춘다. T5 는 변형 3개 중 (i)(ii) 를 만족하는 것의 증가 최대 변형이 그 단계의 T5 후보다.
- 점예측 축: 최종 정보 구성 위에서 P0~P2 중 (i)(ii) 를 만족하는 것의 시드 평균 CV r2_raw 최대(P3 는 참고).
- v2 후보: 누적 경로의 구성 × P0~P2 중 채택 기준(시드 평균 Δr2_raw ≥ +0.10, Δrmse_log ≤ +0.01, 리드타임 ≥ v1)을 만족하는 것 중 CV r2_raw 최대. 없으면 'v2 후보 없음'과 (i)(ii) 를 만족하는 것 중 Δr2_raw 최대 구성을 보고한다.
- 블록 부트스트랩: CV 2020~2024 행을 (연도, 지점) 25블록(보조: 연도 5블록)으로 2000회 복원 추출(시드 42), 같은 블록 뽑기를 세 시드에 똑같이 써서 시드 평균 Δ CV r2_raw 분포를 낸다(예측 고정 — 학습 난수 변동은 시드 평균으로만 반영).
- 2025 는 각 단계 확인용 표시만(선택에 쓰지 않음). 2026 은 읽지 않는다.

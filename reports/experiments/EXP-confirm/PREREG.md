# 확인 실험 사전등록 — 견고성 대안 C (EXP-confirm)

등록 2026-10-22. 이 문서는 실행 전에 커밋한다. 커밋 이후 아래 내용(구성·반복·채택 조건·운영 정의)은 바꾸지 않는다.
배경: `EXP-summary.md` 5절 선택지 C. 사용자 결정(2026-10-22): B 기각, A(v1) 기본, C 는 사전등록 확인 실험 1회로 판정.

## 1. 사용자 지시 원문(그대로)

- 구성: v1 로그 앙상블 + R2 상류 피처 + R3 속별 구성원. 분위 모델은 v1로 고정. 결합 가중치는 2020~2024 CV OOF NNLS. 그 외 변경 금지.
- 반복: 시드 5개, 난수 열 대조군 포함.
- 채택 조건(모두 충족해야 채택):
  (a) CV r2_raw에서 시드별 (C − v1) 차이의 평균 ≥ +0.08, 부트스트랩 95% CI 하한 > 0, 같은 조건의 난수 대조군 대비로도 ≥ +0.04
  (b) 2025 비열등: r2_raw ≥ v1 − 0.02, rmse_log ≤ v1 + 0.01, F1@10k ≥ v1 − 0.02, 리드타임 포착 ≥ 18/20
  (c) 누수 테스트 전부 통과
- 하나라도 못 미치면 v1 유지.
- 2026은 판정을 커밋한 뒤에만, 채택된 모델에 한해 1회 계산해 보고한다. 2026 결과로 판정을 번복하지 않는다.
- 판정 결과와 근거 표만 보고하고, 채택이면 재동결(v2, FROZEN_v2.md) 및 제출·패키지·대시보드 반영 계획을 제시한 뒤 멈춰라.

## 2. 운영 정의(실행 전 확정)

**대상 행과 구간.** `harness.load_base()`(v1 학습·검증 행, 기준일 ≤ 2025-12-31). CV = 2020~2024 OOF 통합(1,278행), 2025 = ≤2024 학습 → 2025(256행). 2026 행은 `guard_no_2026` 으로 차단한다.

**구성 C(시드 s).**
- 회귀 구성원 C1·C3·C2: v1 설정과 하이퍼파라미터(`harness.v1_specs()`). 학습 피처 = v1 30개 + R2 상류 피처 5열.
- R2 상류 피처: `r2_upstream.CHOSEN`(lag 0, 상류 1단계, `up1_cell_log`·`up1_slope3`·`up1_wtemp`·`up1_days`·`up1_diff`). 해평·회남은 NaN. as_of 규칙 함수 `r2_upstream.build_features`.
- R3 속별 구성원 cg: R3 선택 설정(G2 = Microcystis + 나머지 3속, 부분별 log 회귀, smearing, 속별 자기회귀 피처 없음). 학습 피처는 회귀 구성원과 같은 35열이다(EXP-011 의 F2+M3 와 동일, `r_combo.genus_members`).
- 결합: `harness.ensemble_expanding(names=("c1", "c3", "c2", "cg"))`. log 공간 NNLS(합=1)로 결합한다. 연도 Y(2020~2024)의 가중치는 Y 이전 CV OOF 로 적합하고 2020 은 균등이다. 2025 의 가중치는 2020~2024 CV OOF 전체로 적합한다. 점예측은 이 앙상블이다(v1 과 같은 로그 앙상블 방식).
- 분위: v1 동결 분위 모델의 OOF(시드 42, `data/processed/exp/baseline/oof.parquet` 의 q10·q50·q90)를 모든 시드에 그대로 쓴다. 따라서 리드타임은 v1 과 같다.

**비교 기준 v1_s.** v1 구성(피처 30개, C1·C3·C2, 연도 확장 NNLS 3구성원)을 같은 시드 s 로 학습한 것.

**대조군 K_s.** C 에서 R2 상류 피처 5열만 표준정규 난수 5열로 바꾼 구성이다. 난수의 결측 위치는 R2 피처의 결측 위치와 같게 둔다. 생성기 시드는 (20261022, s, 5)이고 `r_combo.control_columns` 를 쓴다. 속별 구성원도 이 35열로 학습한다. 결합·분위는 C 와 같다.

**시드.** (101, 202, 303, 404, 505). 탐색 실험(EXP-004~011)에 쓰지 않은 새 시드이고 LightGBM random_state 에만 적용한다.

**(a) 판정 값.**
- Δ_s = r2_raw_CV(C_s) − r2_raw_CV(v1_s). 시드 평균 Δ̄ ≥ +0.080.
- 부트스트랩 95% CI: (연도·지점) 블록(2020~2024 × 5지점 = 25블록, 행이 있는 블록만)을 복원추출 2,000회 한다. 생성기 시드는 20261022 다. 반복마다 뽑힌 행으로 시드별 Δ_s 를 다시 계산해 평균하고, 그 분포의 2.5 백분위수 > 0 이어야 한다.
- 대조군 대비: 시드 평균 [r2_raw_CV(C_s) − r2_raw_CV(K_s)] ≥ +0.040.

**(b) 2025 비열등.** 기준 v1 = 동결 v1(EXP-baseline, 시드 42). C 값 = 5개 시드 2025 지표의 평균.

| 지표 | 동결 v1 | 조건 |
|---|---|---|
| r2_raw | 0.165829 | C ≥ 0.145829 |
| rmse_log | 0.707870 | C ≤ 0.717870 |
| F1@10k | 0.682353 | C ≥ 0.662353 |
| 리드타임 포착(q90≥10k, 2020~2025 사건) | 18/20 | C ≥ 18/20 |

**(c) 누수 테스트.** `pytest tests/test_no_leakage.py tests/test_exp_r2_upstream.py tests/test_exp_r3_genus.py tests/test_exp_harness.py` 가 전부 통과해야 한다. 전체 pytest 결과도 함께 기록한다.

**판정.** (a)·(b)·(c)를 모두 충족하면 채택(v2 = C)이고, 하나라도 못 미치면 v1 유지다. 결과 표와 판정은 `reports/experiments/EXP-confirm/RESULT.md` 에 쓰고 커밋한다. 채택일 때만 그 커밋 뒤에 2026 test 124 조합을 1회 계산해 보고한다. 2026 결과로 판정을 번복하지 않는다.

**하지 않는 것.** 시드·문턱·구성·대조군 추가 변경, 사후 하위집단 분석, 판정 전 2026 계산.

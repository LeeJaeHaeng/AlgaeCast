### 1.4 피처와 변형

창 = [base_date − lag − 6, base_date − lag] 7일, 변수 v 마다 `aw_{v}_mean7`(평균)·`aw_{v}_slope7`(OLS 기울기/일, 유효 3일 이상)·
`aw_{v}_miss7`(결측 일수 비율). `do_pct` = DO / 포화농도(Benson-Krause, 수온) × 100.

- lag 0: 기준일 당일 일평균까지(v1 기상 일자료 `*_t0` 와 같은 규약). lag 1: 전날까지(당일 일평균에 측정 시각 이후 시간이 섞이는 것을 피함).
- 원천: primary(주 측정소만) / fill(주 결측 칸을 차순위 값으로).
- 1차 8변형: lag {0, 1} × {bio4(Chl-a·DO%·pH·수온, 12열), core6(수온·pH·DO·EC·TOC·Chl-a, 18열), core6_nut(+TN·TP, 24열) × {primary, fill}}.
- 2차 6변형(1차가 모두 v1 미만이어서 열 수를 줄임; 근거는 CV 행의 v1 잔차–피처 순위상관 진단, 3.4절):
  lag {0, 1} × {lvl3(Chl-a·탁도·TOC 평균 3열), chla_ms(Chl-a 평균·기울기 2열), mean8(core6_nut 8변수 평균, fill)}.
- 모델: v1 30개 피처 + 새 열, v1 하이퍼파라미터 그대로(`harness.run_members`) → 연도 확장 NNLS 앙상블.
- 진단(선택에 쓰지 않음): v1 피처 그대로 LightGBM 시드 43·44 재학습, CV 상위 3개 변형의 시드 43·44 재학습.

## 3. 선택과 판정

### 3.1 선택(EXP-PLAN 4절, CV 만 사용)

채택 기준(CV r2_raw +0.10, rmse_log 악화 ≤ 0.01, 리드타임 감소 없음)을 만족하는 변형이 **없다** → CV r2_raw 최대 변형
**R6 lag=1 lvl3 primary**(`aw_chla_mean7`·`aw_turb_mean7`·`aw_toc_mean7`, 전날까지 7일 평균, 주 측정소)를 '기준 미달'로 표시해 보고한다.

`harness.adoption(v1, 선택)` = Δ CV r2_raw **+0.005**, Δ CV rmse_log **+0.005**, 리드타임 18/20(유지) → **pass = false**.
(2025 확인: r2_raw 0.183 vs v1 0.166 — 선택에 쓰지 않았다.)

### 3.4 왜 효과가 없나(진단, CV 행 집계)

v1 앙상블의 log10 잔차와 새 피처의 Spearman 상관(lag 0·fill, CV 1,090~1,260행):

| 피처 | ρ(log 타깃) | ρ(v1 잔차) |
|---|---|---|
| aw_chla_mean7 | 0.270 | 0.129 |
| aw_turb_mean7 | 0.398 | 0.110 |
| aw_toc_mean7 | 0.385 | 0.099 |
| aw_do_pct_mean7 | 0.174 | 0.085 |
| aw_ph_mean7 | 0.132 | 0.080 |
| aw_wtemp_mean7 | 0.698 | 0.040 |
| aw_tp_mean7 | 0.458 | 0.035 |
| 기울기(slope7) 10종 | −0.11~0.05 | −0.004~0.044 |

1. **v1 이 이미 가진 정보와 겹친다.** 자동측정 7일 평균 수온–v1 `wtemp_ma14` ρ = 0.94, Chl-a–`chla_lag1w` 0.69, pH–`ph_t0` 0.64.
   타깃과 강하게 엮인 수온(ρ 0.70)·TP(0.46)는 v1 잔차와는 거의 무관(0.04)하다.
2. **추세(기울기)는 신호가 없다.** 7일 기울기 10종 모두 |ρ(잔차)| ≤ 0.044. 일평균 7일 변화가 7일 뒤 세포수를 현재 세포수 이상으로
   설명하지 못한다.
3. **Chl-a 는 남조류 특이적이지 않다.** 같은 날 측정 기준 log 세포수–자동측정 Chl-a 순위상관이 해평 0.06·강정고령 0.12·칠서 0.35·
   물금매리 0.22·회남 0.57(규조류 등 전체 식물플랑크톤 반영). 원단위 r2 를 좌우하는 극단값(경계 이상) 예측에 기여가 작다.
4. **열을 늘릴수록 나빠진다.** 24열(core6_nut) < 18열(core6) < 12열(bio4) < 2~3열(chla_ms·lvl3). v1 하이퍼파라미터·피처 선택이
   30열·연 250행 규모에 맞춰져 있어, 약한 신호의 열이 많아지면 분할 후보만 늘어난다.

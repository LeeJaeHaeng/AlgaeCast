# EXP-004 — R1 분산 반영 원단위 복원(후처리)

## 1. 목적·설정

- 목적: v1 앙상블 점예측(log 공간 결합, 조건부 중앙값 성격)을 원단위 조건부 평균 쪽으로 옮겨 원단위 R²·NSE 를 높일 수 있는지, 그 대가로 log 지표(rmse_log)를 얼마나 잃는지 확인한다.
- 데이터: `harness.load_baseline()` 의 v1 기준 OOF(2020~2025, 재학습 없음). 분위 q10·q50·q90 는 C1 파라미터의 분위 회귀 OOF. 2026 행은 읽지 않는다(`guard_no_2026`).
- σ(x) = (log10(q90+1) − log10(q10+1)) / (2·1.2816), 로그정규 평균 = 10^(μ + ½·ln10·(kσ)²) − 1.
- 폭 보정 p' = m + s·(p − m)(p = log10(점예측+1)), 단측 폭 보정 p' = p + (s − 1)·max(p − m, 0), 상위 한정 로그정규는 μ > g 인 행에만 로그정규 이동을 더한다.
- (r) 계열(명세 예시 밖 추가): v1 의 log 공간 NNLS 는 smearing 을 거친 C1 을 낮게 가중한다(2021~2025 가중치 0.01~0.28). 구성원 c1·c3·c2 를 원단위 MSE 최소의 볼록 결합(합=1, 비음수, 0.01 격자)으로 다시 묶는 것이 앙상블 수준의 원단위 복원이다. 합 제약 없는 원단위 NNLS (r2) 는 결합 + 배율(인플레이션) 형태다. 참고: `models.ensemble.nnls_weights(log_space=False)` 는 합=1 증강 행이 원단위 크기에서 사실상 작동하지 않아(자유 NNLS 가중치 합 ≈ 2 를 사후 정규화) 쓰지 않았다.
- 계수 적합: `harness.expanding_fit_apply` — 연도 Y 는 Y 이전 CV OOF(2020~Y−1)로 원단위 MSE 최소(격자), 2025 는 2020~2024 전체, 적합 자료가 없는 2020 은 v1 그대로. '제약' 변형은 적합 구간 rmse_log 가 v1 앙상블 대비 +0.005 이하인 후보 중에서만 고른다(채택 기준 0.01 의 절반을 여유로 둠, 후보가 없으면 v1 그대로). 격자: k 0.0~2.0(0.01), s 0.8~1.6(0.01), m 1.0~5.0(0.1), g 2.0~5.0(0.25), 결합 가중치 0.01. 지점별 적합은 지점 적합 행이 40 미만이면 공통 계수.
- (f) 계열은 C1 을 처리(k 또는 m·s 를 C1 단독 원단위 MSE 로 적합)한 뒤 log NNLS(f·f2) 또는 원단위 볼록 결합(f3)으로 다시 묶는다. (r+…) 계열은 (r) 결과에 σ·폭 보정을 겹친다(제약 기준은 계속 v1 앙상블).
- 리드타임 '감시(q90≥10k)' 는 q90 를 바꾸지 않으므로 모든 변형이 v1 과 같다.

변형 목록: `s_smear` (s) 앙상블 전역 smearing, `b_lognorm` (b) 로그정규 평균 μ=ens, `b_lognorm_c` (b') 로그정규 평균 μ=ens, 제약, `c_lognorm_q50` (c) 로그정규 평균 μ=q50, `c_lognorm_q50_c` (c') 로그정규 평균 μ=q50, 제약, `d_stretch` (d) 폭 보정 공통(m=평균), `d_stretch_m` (d2) 폭 보정 공통(m·s 적합), `d_stretch_c` (d') 폭 보정 공통, 제약, `e_stretch_site` (e) 폭 보정 지점별(m=평균), `e_stretch_site_c` (e') 폭 보정 지점별, 제약, `f_c1_lognorm` (f) C1 로그정규 평균 → log NNLS, `f_c1_stretch` (f2) C1 폭 보정 → log NNLS, `f_c1_lognorm_raw` (f3) C1 로그정규 평균 → 원단위 결합, `g_hinge` (g) 단측 폭 보정 공통, `g_hinge_c` (g') 단측 폭 보정 공통, 제약, `g_hinge_site_c` (g'') 단측 폭 보정 지점별, 제약, `h_gated` (h) 상위 한정 로그정규 μ=ens, `h_gated_c` (h') 상위 한정 로그정규 μ=ens, 제약, `r_combine` (r) 원단위 볼록 결합(c1·c3·c2), `r_combine_c` (r') 원단위 볼록 결합, 제약, `r_nnls_free` (r2) 원단위 NNLS(합 제약 없음), `rb_lognorm` (r+b) 원단위 결합 + 로그정규 평균, `rb_lognorm_c` (r+b') 원단위 결합 + 로그정규 평균, 제약, `rd_stretch_c` (r+d') 원단위 결합 + 폭 보정, 제약, `rg_hinge_c` (r+g') 원단위 결합 + 단측 폭 보정, 제약, `rh_gated_c` (r+h') 원단위 결합 + 상위 한정 로그정규, 제약.

- σ·폭 보정 계열(s·b·c·d·e·g·h, r+…)은 원단위 MSE 로 고른 계수가 직전 연도들의 극단값 수에 끌려간다. 2022(>10^5 10행)를 포함해 적합한 2023 계수가 커지고(예: (b) k 0.93, (d) s 1.18), 극단값이 적은 2023 에 과대 예측이 생긴다. CV 2023 r2_raw 가 v1(0.091)보다 0.05 이상 나쁜 변형: `s_smear`, `b_lognorm`, `c_lognorm_q50`, `d_stretch`, `d_stretch_m`, `e_stretch_site`, `e_stretch_site_c`, `f_c1_lognorm_raw`, `g_hinge`, `g_hinge_c`, `g_hinge_site_c`, `h_gated`, `h_gated_c`, `rb_lognorm`, `rd_stretch_c`, `rg_hinge_c`, `rh_gated_c`.
- 로그정규 평균을 그대로 쓰면 원단위 R² 는 오르지만 rmse_log 가 크게 나빠진다((b) +0.060, (c) +0.084; 조건부 평균은 log 오차 최소점이 아니다). rmse_log 제약을 두면 개선 폭이 거의 사라진다((b') +0.008, (c') +0.000).
- smearing 대비(C1 단독): smearing(v1) CV r2_raw 0.306·rmse_log 0.818, 행별 σ 로그정규 평균 0.297·0.896. 분위 폭 σ 는 |log 잔차|와 상관이 0.30 에 그쳐 상수 배수(smearing)보다 나은 점이 없다. 앙상블 전체에 smearing 을 거는 (s) 는 log 잔차 분산이 커서 배수가 4~5 로 나와 크게 나빠진다.
- 원단위 볼록 결합 (r): 가중치가 2023 부터 C1(smearing) 쪽으로 옮겨 가는 것(사실상 C1 단독)이 개선의 원천이다. 계수가 구성원 범위 안이라 과대 예측 위험이 작고, CV 연도 중 v1 보다 0.01 이상 나쁜 해: 없음. CV 폴드 평균 r2_raw 0.218(v1 0.168).
- 선택 변형 `rh_gated_c` 은 통합 CV r2_raw 가 가장 크지만(+0.135) 개선이 2024 에 몰려 있다(2024 0.586 vs v1 0.261, 2023 -0.276 vs v1 0.091, CV 최저 연도 -0.276). CV 폴드 평균 r2_raw 0.176(v1 0.168). 통과 변형 중 CV 폴드 평균 r2_raw 가 가장 큰 (보조 지표 기준 가장 견고한) 변형은 `r_combine`.
- 2025 확인(선택에 쓰지 않음): 선택 변형 r2_raw -0.657·rmse_log 0.731, v1 0.166·0.708. `r_combine` 2025 r2_raw 0.109. 2025 r2_raw 가 v1 보다 높은 변형: 없음. CV 개선이 2025 로 이어지지 않는다. 채택 기준은 CV 로 통과했지만, v2 에 넣을지는 이 확인 결과를 보고 사용자가 정한다.

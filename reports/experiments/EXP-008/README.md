# EXP-008 — R5 전국 조류경보 지점 통합 학습

## 1. 목적·설정

- **목적**: 조류경보제 전 지점(우리 5지점 밖 77곳)의 측정 이력을 학습 표본에 더하면, 우리 5지점의 원단위 R²·NSE가 높아지는지 본다. 특히 10,000 cells/mL를 넘는 희소 고농도 표본이 늘어나는 효과를 확인한다.
- **데이터 수집**
  - 조류경보제 API(`apis.data.go.kr/1480523/nieragainstalgae/algaePreMeasure`)를 `ptNoList` 없이 연도별(`wmyrList`, 1~12월, `numOfRows` 10,000)로 조회했다. 수집기는 새로 만든 `collect/nier_algae_all.py`다. 결과는 **82개 지점, 51,714행(2012-01-03~2026-10-15)**이며 저장 위치는 `data/raw/nier_algae_all/`다. 우리 5지점 2,979행은 v1 원자료(`data/raw/nier_algae/`)와 세포수가 100% 같았다(불일치 0). 알 수 없는 문자열도 0건이었다.
  - 우리 5지점을 뺀 77개 지점의 2025-12-31 이전 측정은 46,143건이고, 그중 10,000 이상이 1,324건이다. 우리 5지점은 2,718건 중 281건이다.
  - 기상청 관측지점 정보는 기상자료개방포털 지점 목록(`data.kma.go.kr/tmeta/stn/selectStnList.do`, 인증 불필요)에서 받았다. 수집기는 새로 만든 `collect/kma_stn_info.py`이고 14,928행이다. ASOS(지점번호 90~299, 남한) 120곳의 이전 이력 좌표 중앙값을 대표 좌표로 썼다.
  - ASOS 일자료는 기존 수집기 `collect/kma_asos.py`로 받았다. `.env` 키를 사용했고 대상은 다른 지점이 쓰는 27개 관측소, 기간은 2012~2025, 저장 위치는 `data/raw/kma_asos_all/`다. 4곳(163·176·239·256)은 API가 `NO_DATA`를 돌려줘 다음으로 가까운 관측소로 넘어갔다.
- **지점 좌표 결정**(`r5_national.site_coordinates`, 지점 목록에 좌표 열이 없음): 아래 순서로 적용했다.
  1. 우리 5지점은 sites.yaml의 lat/lon을 쓴다.
  2. `COORD_REF` 대상 16곳은 기준 지점의 좌표를 쓴다. 대상은 옛 취수장 지점 3곳(상세주소가 우리 지점과 같음), 시범 지점 10곳, 보 직상류 지점 2곳, 의암호다.
  3. 수질측정망 측정소 코드가 조사지점 코드와 같으면 그 좌표를 쓴다(13곳). 측정소 목록은 `data/raw/nier_wq/` GeoJSON을 메모리에서만 해제해 읽었다.
  4. 같은 중권역(코드 앞 4자리) 측정소 가운데 이름이 상세지점명과 같으면 그 좌표를 쓴다(1곳). 수계명 앞 2글자가 측정소명에 들어가면 그 측정소들의 좌표 평균을 쓴다(30곳).
  5. 나머지는 중권역 측정소 좌표 평균을 쓴다(17곳).
- **최근접 ASOS**: haversine 거리가 가까운 순으로 보고, 그 지점 측정 기간의 일평균기온 보유율이 90% 이상인 첫 관측소를 고른다. 모든 기상 변수에 같은 관측소를 쓴다. 거리는 중앙값 13.2 km, 범위 2.7~29.0 km였고, 22곳은 가장 가까운 관측소의 보유율이 모자라 두 번째 관측소를 썼다.
- **수문**: 가용 지점에만 넣었다(`HYDRO_MAP`).
  - 시설 운영자료가 있는 곳은 24곳이다. 낙동강 보·하굿둑(상주·낙단·구미·칠곡·강정고령·달성·합천창녕·창녕함안·하굿둑)과 진양호(남강댐)·용담호·대청호 추동·문의다.
  - 상류 본댐만 있는 곳은 5곳이다(금강 세종·공주·백제보와 시범 2곳).
  - 나머지 48곳은 결측이며 `hydro_fac_available` = 0으로 표시했다. 다른 지점 표본의 보 방류량 결측률은 74%, 연속수위 결측률은 90%다.
- **피처**
  - 다른 지점: v1 함수로 만들었다. 경로는 `align.run.build_site_daily` → `apply_strategy`(S1) → `features.run.build_samples`(features/*)이고, 일 달력은 2012-01-01~2025-12-31이다. 피처 함수의 `site_by_code`·수온 임계 조회에 지점 dict만 `mock.patch`로 덧붙였으며, 파일은 수정하지 않았다.
  - 다른 지점의 수온 임계는 v1 5지점 값의 중앙값인 22.9 ℃로 두었다.
  - 우리 5지점 행은 `harness.load_base()`(v1 `features_S1` 값 그대로)를 썼다.
  - 다른 지점 표본은 **42,166행이고 그중 10,000 이상이 1,235행**이다. 하천은 17,707행 중 1,049행, 호소는 24,459행 중 186행이다. 저장 위치는 `data/processed/exp/EXP-008/other_samples.parquet`다.
- **학습·평가**
  - 모델은 v1 파라미터(`harness.v1_specs()`)의 C1(log 가중, smearing)·C3(hurdle)·C2(tweedie)와 분위 q10/q50/q90이다. v1 `fit_predict`·`fit_quantiles`와 같은 식에 표본 가중만 더했다.
  - 폴드는 기준일 연도로 나눴다. 모든 지점에서 valid 연도 미만 행만 학습하고(Final은 2024 이하 → 2025), 평가는 우리 5지점 행만 한다. 이후 하네스로 연도 확장 NNLS를 하고 표준 지표를 계산했다.
  - smearing 계수는 우리 지점 학습 행의 잔차로 구했다.
- **재현 점검**: `own_only` 변형(다른 지점 0행)으로 코드를 검증했다. c1·c1_none·c1_log·c3·c2·q10·q50·q90 모두 하네스 기준 OOF와 log10 최대 절대차 0이었다. 공개 함수 `members(df, cols)`도 저장한 선택 OOF를 차이 0으로 다시 만들었다.
- **변형**(16개: `own_only` + 통합 15개). 1차 결과를 보고 2·3차를 추가했고, 모든 선택은 CV로만 했다.

| 키 | 설명 |
|---|---|
| `own_only` | 우리 5지점만(재현 점검) |
| `all_embed` / `all_noembed` | 전 지점, 지점 임베딩(`station_id` 범주형) 있음 / 없음 |
| `all_embed_w5`·`_w10`·`_w20` | 전 지점 + 임베딩, 우리 지점 표본 가중 ×5·×10·×20 |
| `all_noembed_w5`·`_w10`·`_w20` | 전 지점, 임베딩 없음, 가중 ×5·×10·×20 |
| `nakgeum_embed` / `nakgeum_noembed_w5` | 낙동강·금강 권역(코드 20xx·30xx와 시범 지점)만 |
| `river_embed` / `river_noembed_w5` | 하천 지점만 |
| `all_hist` / `all_hist_w5` | 수치 지점 임베딩: 지난해까지 측정 이력(평균 log 세포수·10k 이상 비율·측정 수). as_of는 그 해 1월 1일 이전 |
| `prior_own` | 전이: 다른 지점만으로 학습한 C1 log 예측을 피처(`pooled_prior`)로 쓰고, 구성원은 우리 지점만으로 학습 |

## 3. 선택한 변형과 채택 판정

- **선택: `all_noembed_w5`**(전 지점, 지점 임베딩 없음, 우리 지점 표본 가중 ×5). EXP-PLAN 4절 규칙을 따랐다. 채택 기준을 만족하는 변형이 하나도 없어, CV r2_raw가 가장 큰 변형을 **'기준 미달'**로 표시해 보고한다.
- `harness.adoption(v1, 선택)` 결과: d_cv_r2_raw = **+0.090**, d_cv_rmse_log = **+0.015**, lead_ok = True(19/20 ≥ 18/20), **pass = False**. r2_raw 상승폭이 기준(+0.10)에 못 미치고, rmse_log 악화폭도 허용치(0.01)를 넘는다.
- 기준에 가장 가까운 변형은 둘이다. 둘 다 rmse_log·리드타임 조건은 만족하지만 r2_raw가 모자란다.
  - `all_noembed_w10`: +0.087 / +0.006 / 18/20
  - `nakgeum_noembed_w5`: +0.088 / +0.004 / 19/20
- 해석
  - **지점 임베딩(`station_id` 범주형)은 해로웠다.** 같은 가중에서 임베딩이 있으면 r2_raw가 0.218, 없으면 0.263이었다(가중 1에서는 0.182 대 0.211). 82개 수준의 범주 분할이 우리 지점을 따로 떼어 내 다시 작은 표본 적합으로 돌아가는 것으로 보인다. 임베딩이 없으면 지점 차이를 공통 피처(직전 세포수·수온·수문·시설 유형·수계)로 설명해야 해서, 다른 지점의 대발생 동역학이 옮겨 오는 것으로 해석된다. 수치 임베딩(지점 이력)도 임베딩 없음보다 나빴다(가중 ×5에서 0.227).
  - **우리 지점 가중**을 1 → 5 → 10 → 20으로 올리면 rmse_log 악화가 줄었다(0.829 → 0.819 → 0.811 → 0.807). r2_raw는 ×5~×10에서 가장 높았다.
  - 지역을 좁힌 부분집합(낙동강·금강, 하천)은 전 지점과 r2_raw가 비슷하고 rmse_log는 조금 낫다. 다른 수계의 호소 표본(대부분 저농도)은 log 오차만 조금 키운다.
  - 전이 변형 `prior_own`은 rmse_log를 거의 유지했지만(0.806) 리드타임이 14/20으로 떨어졌다. 구성원과 분위를 우리 지점만으로 학습하면서 q90이 낮아진 결과다.
- **2025 확인**(선택에 쓰지 않음): 선택 변형의 2025 r2_raw는 0.169로 v1 0.166과 거의 같다. rmse_log는 0.721로 v1 0.708보다 나쁘다(+0.013). CV 이득(+0.090)이 2025에서 재현되지 않았다. CV에서도 개선은 2021·2022·2024에 몰려 있고 2020·2023은 오히려 낮아, 폴드 평균 이득은 +0.028(0.168 → 0.196)에 그친다. 15개 통합 변형을 같은 CV로 비교했으므로 선택 변형의 CV 수치에는 선택 낙관이 섞여 있다.

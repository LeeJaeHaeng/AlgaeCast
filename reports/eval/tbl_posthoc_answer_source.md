# 2026 사후 분석의 정답 출처 — 대회 번들 끝 이후 측정에 기대는가

- 번들 `algae_measure.csv` 끝: 해평 2026-09-07, 강정·고령 2026-09-07, 칠서 2026-09-10, 물금·매리 2026-09-10, 회남 2026-09-10. 저장소 사후 계산의 조류 원천은 공공 API `nier_algae_2012_2026.parquet`(2026-10-15 까지).
- 저장된 사후 예측(`posthoc_2026_v21.parquet`, v2.1 동결 커밋 217260e 뒤 1회)과 측정만 다시 집계했다. 새 예측 없음. 2026 test 정답은 `eval.live.load_test_targets`(명시 플래그)로만 읽었다. 이 표에는 정답 값 자체를 쓰지 않는다(일치 여부·차이만).
- 재현 확인: API 입력으로 만든 사건이 `transitions.official_events` 와, 2026 리드타임이 `eval.posthoc.leadtime_2026` 과(요약·사건별 상세), 2020~2025 리드타임(q90·B0)이 `transitions.leadtime_table` 과 같음을 확인한 뒤 원천만 번들로 바꿨다.
- '번들 재사용 가능' 기준일 = 번들 기간 안 + 기준일 측정이 번들에 있음 + 기준일까지 모델 입력 조류 열(세포수·수온·pH·클로로필a·우점종, 자기·바로 위 지점)이 번들과 같음 + 목표일 매칭(horizon_days)이 번들 측정일로도 같음 + cell_log_t0 이 번들 세포수와 같음. 이 행은 번들만으로 계산해도 같은 예측이므로 저장 예측을 그대로 쓴다.

## 3. 정책 브리프 (4쪽) 목차
1. **요약** (반 쪽): 문제, 해법, 핵심 수치 3개, 권고 3줄
2. **현황 진단** (1쪽): 경보 발령일수 추이, **2026년 이례적 조기 발령(관심 5.18) vs 장기 추세 비유의(지점 평균 제거 잔차 Mann-Kendall, Sen −1.0일/년, p=0.64; T2 S7)** — 연도 간 변동이 크다는 사실 자체가 핵심, 급증 사례, 취수원 위험 노출(물금 33%). 결론: **고정 달력 대신 예측 기반 탄력 운영 필요**. 발표·브리프 모두 '매년 빨라진다' 식 과장 금지
3. **7일 선행 예측의 가치** (1쪽): 설비 가동 원칙('경계' 시) vs 리드타임, 확률 경보 체계, 설비 배치 시뮬레이션(최근 2년 사후 적용 시 선제 배치 가능했던 건수), 고도정수 전환·취수 심도 조정 연계
4. **정책 제언** (1쪽): ① 녹조계절관리제 시작 시점을 예측 기반으로 탄력 운영 ② 조류경보제 운영에 확률 예보 병행 공표 ③ 경보제 29개소 53지점 확대 로드맵과 필요 데이터(수질자동측정망 확충) ④ 공공 데이터 품질·AI-Ready화(국가연구데이터법 2027 시행 연계)
5. **부록** (반 쪽): 데이터 출처·라이선스, 모델 성능 표, 재현 링크

톤: 수치 중심, 한 문단 3줄 이내, 그림 4개(연도별 첫 발령일 변동(fig_onset_trend), 예측 vs 실측, 확률 경보 예시, 설비 배치 시뮬레이션).

## 4. 예상 질문과 답변 골격
| 질문 | 답변 요지 |
|---|---|
| 누수 없다고 어떻게 보장? | as_of 강제 + 단위 테스트 + 평가조합 감사 로그, 재현 diff 0 |
| 예보 데이터는 미래 정보 아닌가? | 기준일에 공표된 예보 = 기준일에 알 수 있던 정보. 관측값이 아님. ablation으로 기여도 공개 |
| NIER 공식 예측과 비교가 공정한가? | 동일 (site, base_date, target_date)만, n 명시, 가용 기간 한정, 공식 예측이 더 나은 지점도 그대로 보고 |
| R² 0.6 못 넘으면? | CI와 함께 보고, log 지표·F1·PICP로 운영 가치 입증, 대발생 민감도 설명 |
| 현업 적용 비용? | 공공 API + 무료 티어 인프라, 일일 배치 10분, 추가 센서 불필요 |
| 다른 지점 확장? | 지점 범주형 + 정적 제원 피처라 데이터만 있으면 재학습 없이 추론 가능(검증 필요) |
| 결측이 많은 겨울은? | 조류 시즌 한정 학습·예측, 비시즌은 "예측 불가" 명시 |
| 설비 배치 가중치 근거? | 취수능력·인구 기반, config로 공개, 담당자가 조정 가능 |

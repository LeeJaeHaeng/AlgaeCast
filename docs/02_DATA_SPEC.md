# 02. 데이터 명세서

## 1. 원칙
- 대회 제공 데이터가 1차 소스. 외부 데이터는 **보강** 목적이며, 모두 공공누리 또는 "이용허락범위 제한 없음" 라이선스.
- 모든 외부 수집은 `data/raw/MANIFEST.md`에 (데이터명, 기관, URL/ API 엔드포인트, 수집 일시, 기간, 라이선스, 파일 해시) 기록.
- 수집기는 `src/algaecast/collect/<source>.py`, 함수 시그니처 `fetch(site_code: str, start: date, end: date) -> pd.DataFrame`.
- 공통 출력 컬럼 규약: `site_code, obs_date(date), <variable columns>, source, fetched_at`.

## 9. 수집기 공통 요구사항
- 키 컬럼: 지점 단위 자료는 `site_code`(조사지점코드) + `station_id`(대회 약어), 시설 단위 자료는 `dam_code`(WAMIS) / `stn_id`(ASOS). 시설→지점 결합은 `config/sites.yaml` 매핑으로 align 단계에서 수행 (T0-b 확정)
- 예외(T0-b 확정): `dam_operation_api`(HY-01 보조)는 응답에 댐코드가 없어 `dam_name` 키 → `config/sites.yaml` dams[].name 으로 WAMIS 코드에 매핑. `sample_submission` 은 제출 형식 4열 그대로 유지(source/fetched_at 미부여)
- `fetched_at` = **소스 스냅샷 시각**(API 호출 시각, 파일 자료는 생성·기준일). 다운로드(수집) 일시는 MANIFEST 에만 기록한다. 대회 번들은 README 생성일 2026-09-12 00:00 KST 를 쓴다
- 비수치 토큰: 수치 컬럼의 빈칸과 명시 허용 토큰('정량한계미만' → `*_below_loq`, '분석중' → `*_pending`)만 NaN 으로 바꾸고, 그 외 문자열은 로더가 ValueError 로 중단한다(새 토큰 묵살 방지)
- ASOS 무강수 빈칸: 기온·습도 등 관측이 있는 날만 `sum_rn`/`hr1_max_rn` 을 0 으로 채우고(`day_observed`), 관측소 결측일은 NaN 유지
- `serviceKey`는 `.env` (`DATA_GO_KR_KEY`, `KMA_APIHUB_KEY`), 절대 커밋 금지
- 페이지네이션 자동 처리, 응답 캐시(`data/raw/cache/<sha1(url)>.json`)
- 실패 시 3회 재시도(1·2·4초), 최종 실패는 `data/raw/collect_errors.log`
- 출력은 parquet + 동일 내용 csv(검토용)
- 단위 통일: 세포수 cells/mL, 수온 ℃, 강수 mm, 유량 ㎥/s, 저수량 백만㎥, 저수율 %
- 날짜 타임존 Asia/Seoul, `obs_date`는 date 타입

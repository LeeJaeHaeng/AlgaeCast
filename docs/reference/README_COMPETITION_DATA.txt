대회 제공 데이터 — 심사용 (공개 시 제외, 대회 종료 후 폐기)
=================================================================

이 폴더(data/raw/competition/)는 2026 DATA·AI 분석 경진대회 운영사무국이 참가자에게 제공한 자료다.
- 04_sample_data_public.xlsx (대회 공개 샘플)
- datas_participants.zip → algae_contest_2026/ (참가자 번들), 03_collect_dataset.py, 06_data_dictionary.xlsx

심사용으로만 넣었다. 이 패키지를 공개(저장소·웹 게시·배포)할 때는 이 폴더를 빼야 하며, 대회가 끝나면 폐기한다.
저장소(git)에는 처음부터 커밋하지 않았다.

참가신청서 경진대회 규정 3항(요지)
- 제공 데이터는 승인된 목적(이 경진대회) 외로 이용하지 않는다.
- 제3자에게 열람·제공·대여·판매하지 않는다.
- 대회가 끝나면 폐기한다.
- 이 데이터로 성과물이 생기면 출처를 밝힌다.
  출처: 2026 DATA·AI 분석 경진대회(KISTI) 제공 데이터 (원출처: 국립환경과학원 조류경보제, K-water, WAMIS, 기상청 — 번들 README 출처표)

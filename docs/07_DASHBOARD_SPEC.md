# 07. 대시보드 화면 설계서

## 1. 목적과 사용자
| 사용자 | 하고 싶은 일 | 핵심 화면 |
|---|---|---|
| 심사위원 (발표평가) | 2분 안에 "무엇을 예측하고 어떻게 쓰이는지" 이해 | 홈(지도+랭킹), 지점 상세 |
| K-water 운영 담당자 | 오늘 어느 지점에 설비를 보낼지 결정 | 홈 랭킹, 지점 상세 권고 카드 |
| 정책담당자 | 조기화 추세, 모델 신뢰도 | 인사이트, 성능 페이지 |

## 2. 정보 구조 (라우트)
```
/                       홈: 지도 + 지점 카드 + 설비 배치 랭킹 + KPI
/sites/[site_id]        지점 상세: 7일 예측 차트, 경보 확률, 예측 근거, 사후검증, 수문·기상
/performance            모델 성능: 지표 표(CI), 베이스라인·NIER 비교, 지점별·월별 분해
/insights               정책 인사이트: 경보 조기화 추세, 급증 사례, 계절관리제 시사점
/about                  데이터 출처·라이선스, 방법론 요약, 재현 안내, 팀
```

## 3. 화면별 명세

### 3.1 홈 `/`
```
┌──────────────────────────────────────────────────────────────┐
│ AlgaeCast-7  [최근 갱신 2026-10-20 03:05 · 모델 v1.3]  [성능][인사이트][소개] │
├───────────────┬──────────────────────────────────────────────┤
│ KPI 4개       │ 지도 (낙동강·금강 5지점 마커, 색 = p_over_10k)  │
│ ·경보 중 지점 2│                                              │
│ ·7일 내 경계   │  마커 hover: 지점명, q50, p10k, 현재 단계      │
│  확률≥50% 1   │  클릭 → /sites/[id]                          │
│ ·검증 R² 0.63 │                                              │
│ ·F1@10k 0.71  │                                              │
├───────────────┴──────────────────────────────────────────────┤
│ 설비 배치 우선순위 (오늘)                                     │
│ 1 물금·매리  p10k 41%  q50 8,200  ▶ 제거설비 선제 배치 권고    │
│ 2 강정·고령  p10k 23%  ...        ▶ 모니터링 강화             │
│ ...                                                          │
├──────────────────────────────────────────────────────────────┤
│ 지점 카드 5개 (스파크라인 180일 + 7일 예측 점 + 경보선)        │
```

컴포넌트: `KpiTile`, `SiteMap`(Leaflet, OSM 타일), `PriorityTable`, `SiteCard`(Recharts LineChart 미니)

### 3.2 지점 상세 `/sites/[site_id]`
```
┌ 헤더: 지점명 · 수계 · 시설 · 현재 경보 단계 배지 · base_date 선택(DatePicker) ┐
├ 메인 차트 (Recharts ComposedChart)                                           │
│   x: 날짜(최근 180일 + 7일), y: log 축 cells/mL                               │
│   관측(점+선), 예측 q50(점), q10~q90 밴드(Area), 경보선 1k/10k/1M(ReferenceLine) │
│   과거 예측 vs 실측(작은 점, 사후검증)                                         │
├ 좌: 경보 확률 게이지 3개 (관심/경계/대발생)   우: 권고 카드                    │
│   p1k 93% / p10k 41% / p1M 0%                 "제거설비 선제 배치 권고 (우선순위 1)" │
│                                               근거 문장(rationale_ko)         │
├ 예측 근거 (SHAP) — 가로 막대 5개, 그룹명+기여% + 방향 화살표                     │
│   "수온 상승 58%  방류량 감소 24%  누적강우 부족 11%  ..."                      │
├ 수문·기상 보조 차트 (탭: 수온 / 강우·유입·방류 / 저수율·체류시간)              │
└ 사후 검증 표: 최근 20건 base_date, 예측 q50, 실측, 오차, 경보 적중 여부           ┘
```

### 3.3 성능 `/performance`
- 표 1: 2025 holdout 지표 + 95% CI (R²·NSE·RMSE_log·MAE_log·F1@10k·PICP)
- 표 2: 베이스라인 B0~B4 vs 모델 (개선율 %)
- 표 3: NIER 공식 예측 vs 모델 (동일 조합, n 표기)
- 차트: 지점별 R² 막대, 월별 RMSE 선, 예측-실측 산점도(log)
- 결측 전략·ablation 표 접기(아코디언)

### 3.4 인사이트 `/insights`
- 연도별 첫 경보일 점+추세선 (Mann-Kendall p값 표기)
- 연도별 경보 발령일수 막대 (물금·매리 196/146/160/194)
- 급증 사례 타임라인 (강정고령 8.13→8.18 10배)
- 텍스트 블록: 계절관리제 시작 시점 시사점, 설비 배치 시뮬레이션 요약

### 3.5 소개 `/about`
- 데이터 출처 표(기관·라이선스·링크), 방법론 요약 다이어그램, GitHub 링크, 재현 명령 3줄, 팀

## 5. 상태·데이터 흐름
- 서버 컴포넌트에서 fetch → props. 클라이언트 상태는 base_date 선택과 탭뿐 (`useSearchParams`).
- 로딩: Suspense + Skeleton. 오류: 섹션 단위 ErrorBoundary.
- 숫자 포맷: cells/mL 천 단위 콤마, 확률 % 정수, 날짜 `MM.DD`.

## 6. 접근성·품질
- 색만으로 단계를 구분하지 않음(배지 텍스트 병기)
- Lighthouse 성능 ≥ 90, 접근성 ≥ 90
- `npm run build` 경고 0, ESLint 통과

## 7. 데모 시나리오 (영상·발표 공통, 90초)
1. 홈: KPI → 지도에서 물금·매리 마커 붉은색 확인 (10초)
2. 랭킹: "1순위 물금·매리, 제거설비 선제 배치" (10초)
3. 지점 상세: 180일 관측 + 7일 예측 밴드, 경계선 교차 (20초)
4. 경보 확률 게이지 → 권고 카드 → SHAP "수온 상승 58%" (20초)
5. 사후 검증 표: 지난 예측이 맞았는지 (10초)
6. 성능 페이지: R² 0.6x, NIER 대비 (10초)
7. 인사이트: 첫 경보 조기화 추세 (10초)

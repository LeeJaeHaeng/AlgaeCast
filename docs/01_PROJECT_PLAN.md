# 01. 상세계획서

## 1. 배경과 문제 정의

### 1.1 사회적 배경 (문제 설명서 인용·요약)
- 폭염 장기화·강우 패턴 변화로 상수원 녹조 발생이 확대되고 시기가 조기화됨. 물금·매리 경보 발령일수 '22년 196일, '23년 146일, '24년 160일, '25년 194일.
- 강정·고령 '26년 첫 경보 5.18 발령 — 최근 3년 첫 발령(6월 말~7월 초) 대비 약 2개월 조기화.
- 강정·고령 세포수 8.13 49,400 → 8.18 483,021 cells/mL, 5일 만에 약 10배 급증.
- 조류독소 마이크로시스틴(MC-LR)은 IARC Group 2B. 물금취수장은 부산 먹는물 약 33%(84만 톤/일) 담당.
- K-water는 녹조제거설비 22대·물환경설비 431대·조류차단막 59개소 운영. 제거설비는 '경계' 발령 시 가동 원칙 → **7일 선행 예측으로 설비 선제 배치 리드타임 확보**가 수요기관의 명시적 목적.

### 1.2 과제 정의 (대회 규정)
- 경보제 지점별 base_date부터 향후 7일 유해남조류 세포수(cells/mL) 예측 — **회귀 단일 과제, 배점 100%**
- 정답 = base_date+7일에 가장 가까운 측정일 값(±3일 이내만 채점)
- 평가: log10(세포수+1) RMSE·MAE + 원단위 R²·NSE, 보조 F1(≥10,000 cells/mL)
- 분할: 학습 ~2024 / 검증 2025 / 평가 2026(sample_submission 조합)
- 목표 성능: R² 0.6, NSE 0.5 이상
- 벤치마크: 국립환경과학원 AI '녹조 정밀 예측정보'('26.5.4~, 7일, 13개소)

## 3. 핵심 전략 (심사 항목 매핑)

### 3.1 우수성 50점
1. **3도메인 융합 방법론 문서화**: 주간(비정기) 수질 ↔ 일 단위 수문·기상 정렬 규칙, 누적·이동평균·체류시간 대리변수 설계를 독립 장으로.
2. **결측 대체 전략 평가**: 문제 설명서가 명시한 항목. 전진채움 / 선형보간 / 모델기반(KNN·MICE) 3전략 × 성능표.
3. **누수 방지 공학**: `as_of` 규칙 강제 + 단위 테스트 + 평가조합 입력 날짜 로그. 재현 검증 통과가 곧 완성도.
4. **벤치마크 비교**: NIER 공식 AI 예측(2026.5.4~) 동일 지점·기간 비교표.
5. **통계적 엄밀성**: 부트스트랩 CI, Diebold-Mariano, 잔차 진단, ablation.

### 3.2 효과성 30점
1. **Vercel 배포 대시보드**: 지도 → 지점 → 7일 예측 밴드 → 경보 확률 → 설비 배치 권고. 심사위원이 직접 접속 가능한 URL.
2. **일일 자동 파이프라인**: GitHub Actions가 매일 새벽 공공 API 수집·추론·Supabase 업로드. "내일부터 운영 가능"의 증거.
3. **정책 브리프 4쪽**: 조기화 통계 검정, 계절관리제 기간 시사점, 설비 배치 시뮬레이션 결과.
4. **데모 영상 2분**.
5. **2단계 경보 운영 체계(T5 확정)**: 감시(watch) = CQR 보정 q90 ≥ 10,000 → "모니터링 강화·설비 준비 점검" / 경보(alert) = 분류기(b, +4~+10일 창) p ≥ 0.52(비용비 r=3 운영점) → "녹조제거설비 선제 배치 권고" / 둘 다 아니면 정상(normal).
6. **헤드라인(전 문서·대시보드·발표 통일, 2026-10-21 갱신)**: "동결 모델이 처음 보는 2026년 경계 사건 8건 중 7건을 중앙 21일 앞서 감시 단계로 포착(지속성 2건). 2020~2026 합계 28건 중 25건(89%, 중앙 14일 앞서), 지속성 3건." 각주: 리드타임은 첫 경계 초과 측정일 기준이며 공식 발령일 기준으로는 2020~25 중앙 21일·2026 중앙 31일. 출처 reports/eval/tbl_leadtime.md, tbl_holdout_2026_posthoc.md.

### 3.3 창의성 20점
1. **예보 데이터의 합법적 활용**: base_date에 발표된 기상청 단기·중기예보를 피처화(AIDA MAPLE 실황예측은 계획했으나 미사용). "기준일 이후 관측값 금지" 규정을 지키며 미래 기상 정보를 쓰는 유일한 경로.
2. **점추정 → 확률 경보**: 분위 회귀(0.1/0.5/0.9)로 7일 내 경계 초과 확률 산출.
3. **의사결정 최적화**: 확률 × 취수량 가중치 → 제거설비 우선순위(간단한 greedy 할당).
4. **설명가능성**: SHAP를 담당자 언어로 번역("수온 상승 기여 60%").

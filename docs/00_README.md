## 프로젝트 한 줄 정의

## 용어
- **base_date**: 예측 기준일. 실제 측정이 존재하는 날짜.
- **target_date**: base_date + 7일에 가장 가까운 실제 측정일(±3일 이내). `sample_submission.csv`에 지정.
- **타깃 변수**: `iem_bgalage_cell_co` — 유해남조류 4속(Microcystis, Anabaena(Dolichospermum), Oscillatoria, Aphanizomenon) 세포수 합계 (cells/mL).
- **경보 단계(상수원 구간, 2025.12.30 개정 물환경보전법 시행령 별표3)**: 관심 ≥1,000 / 경계 ≥10,000 또는 조류독소 ≥10 μg/L / 대발생 ≥1,000,000 (2회 연속 측정 기준).
- **NSE**: Nash–Sutcliffe Efficiency = 1 − Σ(obs−pred)² / Σ(obs−mean(obs))².

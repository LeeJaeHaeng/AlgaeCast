### 화면을 그리는 규칙

- **예측**
  - 고정 run `9269d95d-9b8f-4d12-babe-02f9f60b41c5`(v2.1)의 지난 예상값을 쓴다. DB 에 이미 저장된 값이다.
  - 지점마다 기준일 ≤ 그날인 가장 최근 것을 고른다.
  - run 을 고정했기 때문에, 새 run 이 생겨도 장면이 사라지지 않는다.
- **관측·사건·상황 기록**
  - 관측은 관측일 ≤ 그날만 쓴다.
  - 사건은 공식 발령일 ≤ 그날만 쓴다.
  - 상황 기록은 그날 −30일~그날이다. 예상 단계 변화는 고정 run 예측으로 만든다.
  - 모두 서버 조회 단계(`.lte`)에서 거른다.
  - 예측 행의 실측은 목표일 ≤ 그날일 때만 붙인다. DB 에 비어 있으면 관측으로 채운다(DB 쓰기 없음).
- **허용 범위: 2026-05-04~2026-10-22**
  - DB 의 2026 기준일 예측은 05-04 부터 있다.
  - 2025년 이전은 v2.1 학습기간(≤2025)과 겹쳐 '그날까지의 자료만'이 성립하지 않는다. 그래서 뺐다.
  - 범위 밖이나 형식 오류는 기본 화면과 쉬운 말 안내로 처리한다.
- **화면 위 띠**(늘 맨 위, 지정 문구 그대로): "다시 보기 — YYYY-MM-DD 기준. 동결 모델(v2.1)로 그날까지의 자료만 써서 사후 계산한 화면이며, 당시 실시간 운영 화면이 아닙니다."
  - 띠 오른쪽 버튼: '그 뒤 실제로는?(21일 보기)', '현재 화면으로 돌아가기'.
  - 띠에는 장면 이름(결과를 알려 주는 말)을 넣지 않았다.
- **'그 뒤 실제로는' 토글**
  - 기본은 꺼짐이다.
  - 켜면 그날 뒤 21일 실측을 분홍색 점선과 점으로 겹친다. '그날' 선은 보라 실선이다.
  - 꺼져 있으면 서버가 그 21일 자료를 아예 가져오지 않는다.
  - 차트가 없는 /log 에는 토글이 없다.
- **실시간 요소**
  - 다시 보기에서는 시계·마지막 갱신·5분 자동 갱신·실시간 강조를 끈다.
  - 성적표 띠는 그날 뒤 사건으로 매긴 수 대신 안내와 링크로 바꾼다.
  - 다시 보기 안의 링크는 asof 를 유지한다.
